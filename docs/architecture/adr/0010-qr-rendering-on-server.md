# 0010. QR-коды генерирует сервер (матрица), Godot только рисует

- **Статус:** Accepted
- **Дата:** 2026-10-30
- **Связанные задачи:** SRV-006, GDT-003, GDT-007

## Контекст

Godot 4.7 не имеет встроенного генератора QR. Godot должен показывать QR привязки и QR улик.

## Рассмотренные варианты

1. **Аддон QR для Godot** — дополнительная зависимость с отдельным циклом обновлений, требует
   проверки совместимости с каждой версией Godot.
2. **Сервер генерирует PNG** — просто, но Godot теряет контроль над стилем (глитчи, цвета, искажения).
3. **Сервер возвращает матрицу модулей** (`{ size, modules: string }`, строка из `0/1` по строкам)
   через библиотеку `qrcode` (MIT); Godot строит `Image` и рисует с собственным стилем.

## Решение

Вариант 3. Эндпоинты: `GET /api/v1/sessions/:id/pairing-qr` и
`GET /api/v1/sessions/:id/evidence-qr/:tokenId` (авторизация `desktopToken` в заголовке
`Authorization: Bearer`). Уровень коррекции ошибок — `M`; Godot рисует с «тихой зоной» 4 модуля
и минимальным размером модуля 6 px при разрешении 1080p.

## Последствия

- Нет Godot-зависимостей для QR; стилизация (рамки, шум вокруг) остаётся в Godot, но сам код
  не искажается — читаемость проверяется на реальных телефонах (INT-003).
