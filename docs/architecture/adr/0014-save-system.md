# 0014. Сохранения: seed + версия генератора + журнал действий + контрольный хеш

- **Статус:** Accepted
- **Дата:** 2026-10-30
- **Связанные задачи:** SAVE-001, SRV-007, QA-004

## Контекст

Нужно сохранять и восстанавливать игру, включая время, расписания, очередь событий, знания NPC.
Roguelike-игре нужны сохранения «на выход» (suspend), а не произвольные слоты для скамминга.

## Решение

Формат `SaveFile` (JSON):

```json
{
  "formatVersion": 1,
  "generatorVersion": "0.1.0",
  "protocolVersion": 1,
  "scenarioId": "sanatorium_winter",
  "seed": "frost-7731",
  "createdAt": "2026-10-30T18:00:00Z",
  "actions": [ { "seq": 1, "source": "desktop", "action": { "type": "move", "to": "lobby" } } ],
  "checkpoint": { "atAction": 120, "stateHash": "sha256:…", "snapshot": { } },
  "finalStateHash": "sha256:…"
}
```

- **Загрузка:** регенерация расследования по `(scenarioId, seed, generatorVersion)` и повтор
  действий; если есть `checkpoint` и хеш совпадает — загрузка снимка и повтор только хвоста.
  В конце сверяется `finalStateHash`; расхождение — ошибка `SAVE_DESYNC` (с отчётом).
- **Модель roguelike:** одно активное сохранение на прохождение; автосохранение после каждого
  действия (запись журнала дешёвая), чекпойнт-снимок каждые 50 действий.
- `createdAt` — метаданные сервера, не участвуют в игровой логике.
- Сохранения хранятся на сервере (`HS_DATA_DIR/saves/<sessionId>.json`).

## Последствия

- Сохранения компактны и одновременно являются репро-кейсами для багов.
- Несовместимая версия генератора требует миграции или запрета загрузки (QA-004).
