# 0004. Детерминизм: seed-подпотоки PRNG, целочисленное время, запрет недетерминированных API

- **Статус:** Accepted
- **Дата:** 2026-10-30
- **Связанные задачи:** CORE-001, CORE-002, FND-002, VAL-008, SAVE-001

## Контекст

Одинаковые `(scenarioId, seed, generatorVersion, последовательность действий игрока)` должны давать
идентичный мир, расследование и поведение персонажей. От этого зависят сохранения (ADR 0014),
воспроизведение багов по seed, регрессионные корпуса и валидация.

## Решение

1. **PRNG:** собственная реализация `sfc32` (32-битная, быстрая, переносимая) с хешированием
   строкового seed функцией `cyrb128`. `Math.random()` запрещён в `@hs/core`, `@hs/generator`,
   `@hs/validator` (ESLint-правило).
2. **Подпотоки:** `rng.fork(label)` создаёт независимый поток из `hash(parentSeed, label)`.
   Каждая стадия генерации и каждый персонаж в симуляции получают свой подпоток
   (`gen/cast`, `sim/agent/<characterId>`). Добавление вызова RNG в одной стадии не меняет результаты
   других стадий.
3. **Время:** целое число игровых минут от начала сценария (`GameMinutes`). Никаких `Date.now()`,
   `new Date()`, `performance.now()` в логике ядра; календарь вычисляется из `startDateTime` пресета.
4. **Порядок итерации:** коллекции, влияющие на результат, обходятся в отсортированном по `id`
   порядке. Обход `Map`/`Set` допустим только если порядок вставки детерминирован.
5. **Числа с плавающей точкой:** допустимы для весов/вероятностей; сравнения порогов только после
   округления до фиксированной точности (`roundTo(x, 6)`), чтобы исключить расхождения платформ.
6. **Хеш состояния:** `stateHash = sha256(canonicalJson(snapshot))` — используется в тестах
   детерминизма и при загрузке сохранений.
7. **Версия генератора:** `GENERATOR_VERSION` (semver) в `@hs/generator`. Любое изменение,
   меняющее результат для существующего seed, увеличивает minor-версию и обновляет golden-снимки.

## Последствия

- Golden-тесты на фиксированных seed ловят непреднамеренные изменения.
- Разработчики не могут использовать удобные недетерминированные API — это проверяется линтером.
- Сохранения старой версии генератора не загружаются новой без миграции (QA-004).
