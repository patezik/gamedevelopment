# 0006. Генерация «сначала мир — потом виновник» + валидатор как обязательный шлюз

- **Статус:** Accepted
- **Дата:** 2026-10-30
- **Связанные задачи:** GEN-001…GEN-010, VAL-001…VAL-008

## Контекст

Нельзя заранее задавать список подозреваемых. Любой участник сценария может оказаться виновником,
если это допускают причинно-следственные ограничения. Расследование обязано быть логически
непротиворечивым и решаемым.

## Рассмотренные варианты

1. **Шаблон преступления с фиксированными ролями** («убийца», «свидетель») — быстро, но нарушает
   ключевое требование и ведёт к однотипным прохождениям. Отклонено.
2. **Обратная генерация от решения** («сначала выбрать виновника, затем подогнать мир») — проще
   гарантировать решаемость, но персонажи становятся функциями сюжета.
3. **Генерация мира, затем выбор виновника среди всех допустимых участников по выполнимости**
   (мотив, средства, возможность, способность) + генерация плана и следов + валидатор с ограниченным
   числом детерминированных попыток ремонта/перегенерации.

## Решение

Вариант 3. Конвейер стадий (подробно — [generation-pipeline.md](../../procedural-generation/generation-pipeline.md)):

`WorldGen → CastGen → SocialGen → ConflictGen → IncidentSelection → PlotPlanning →
HistorySimulation → EvidenceGen → TestimonyGen → RedHerrings → Validation → Packaging`

- Виновник выбирается взвешенно из множества `feasibleCulprits` — всех персонажей, прошедших
  проверку выполнимости. Списка «Suspects» в данных нет.
- Валидатор — обязательный шлюз: расследование, не прошедшее проверку, не отдаётся игре.
- При провале: до `maxAttempts` (по умолчанию 8) попыток с подсидами `seed#1…#8`
  (сначала стратегии ремонта — добавить избыточный след, сдвинуть расписание; затем перегенерация
  с другой стадии). Если все попытки неудачны — ошибка `GENERATION_UNSOLVABLE` и запись seed в отчёт.
- Метрика качества пресета в seed sweep: доля неудач < 1 %, энтропия распределения виновников по
  персонажам ≥ 0,8 от максимальной (никто не виновник «почти всегда»).

## Последствия

- Генерация дороже (симуляция предыстории + валидация), бюджет — 500 мс на расследование MVP
  в Node.js на среднем ПК (QA-002).
- Пресеты должны описывать ограничения, а не роли; авторам контента нужен гайд
  ([scenario-presets.md](../../procedural-generation/scenario-presets.md)).
