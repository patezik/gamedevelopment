# 0011. Godot 4.7.2, GDScript со строгой типизацией, GUT 9.7.x

- **Статус:** Accepted
- **Дата:** 2026-10-30
- **Связанные задачи:** FND-007, FND-008, GDT-001…GDT-011

## Контекст

Godot обязателен. Нужно выбрать версию, язык, тестовый фреймворк и минимальный набор аддонов.

## Решение

- **Godot 4.7.2-stable** (выпущен 18.08.2026; ветка 4.7 — с 18.06.2026). Стандартная сборка
  (не .NET). Версия фиксируется в `apps/desktop/project.godot` (`config/features`) и в
  [tech-stack.md](../tech-stack.md). Обновление патч-версий 4.7.x — без ADR; переход на 4.8 —
  новый ADR.
- **GDScript** со статической типизацией: в настройках проекта предупреждения
  `untyped_declaration`, `unsafe_*` повышены до ошибок. C# не используется (нет обоснованной
  необходимости; требует .NET-сборку Godot и усложняет экспорт).
- **GUT 9.7.x** (MIT) — 9.7.0 содержит изменения совместимости для Godot 4.7. Аддон
  вендорится в `apps/desktop/addons/gut/` с фиксированной версией; тесты запускаются
  headless: `godot --headless -s addons/gut/gut_cmdln.gd`.
- **Сеть:** встроенные `HTTPRequest` и `WebSocketPeer`. **JSON:** встроенный `JSON`.
- **Архитектура:** Autoload-сервисы `Backend`, `GameStore`, `SceneRouter`, `Settings`,
  `AudioDirector`; общение систем через сигналы; игровые данные клиента — `Resource` только для
  статического контента представления (иконки, стили), но не для правил.
- Других аддонов нет. Любой новый аддон — через ADR с проверкой версии, лицензии и поддержки.

## Последствия

- CI скачивает Godot 4.7.2 headless (официальный релиз с GitHub) и кэширует его.
- Строгая типизация снижает ошибки агентов, но требует явных типов в каждом скрипте.
