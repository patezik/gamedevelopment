# 0013. Событийная симуляция персонажей с уровнями детализации

- **Статус:** Accepted
- **Дата:** 2026-10-30
- **Связанные задачи:** SIM-001…SIM-007, TIME-002, TIME-003

## Контекст

Персонажи действуют автономно и вне видимости игрока. Симулировать каждую минуту каждого
персонажа в многодневном сценарии дорого и не нужно. Симуляция должна быть детерминированной.

## Решение

1. **Событийная модель.** Нет глобального тика по минутам. Персонаж планирует `Activity`
   (последовательность шагов с длительностями); завершение шага — событие в общей очереди
   `Scheduler`. Время продвигается действиями игрока (TimeSystem), очередь обрабатывается до
   нового момента времени.
2. **Уровни детализации (LOD):**
   - `focus` — персонажи в локации игрока и соседних, а также «сюжетно активные»
     (виновник во время сокрытия, персонажи с активной целью). Шаги до 5 минут, наблюдения
     вычисляются по каждому событию.
   - `background` — остальные. Обрабатываются на границах блоков расписания и по триггерам;
     встречи вычисляются пересечением интервалов присутствия в локациях.
   Переход между уровнями не меняет уже записанную истину; он влияет только на детализацию будущих
   событий. Поскольку уровень зависит от действий игрока, результат детерминирован при той же
   последовательности действий.
3. **Принятие решений.** Утилитарный выбор намерения (utility AI) из набора целей; веса зависят от
   личности, знаний, стресса, отношений. Равенство разрешается подпотоком RNG персонажа.
4. **Бюджет:** продвижение времени на 60 игровых минут при 8 персонажах — не более 10 мс в Node.js
   (QA-002); 3 игровых дня предыстории — не более 200 мс.

## Последствия

- Нет «мгновенной телепортации»: перемещение всегда занимает время по графу локаций.
- Отладка через журнал истины: любое действие NPC оставляет `TruthEvent`.
