# 0007. Мобильный стек: Expo SDK 58, Expo Router, Zustand, Expo Go-first

- **Статус:** Accepted
- **Дата:** 2026-10-30
- **Связанные задачи:** FND-006, MOB-001…MOB-011, INT-007, REL-002

## Контекст

Companion-приложение — нативное React Native приложение (не PWA), запускаемое на начальном
этапе в Expo Go. Нужны камера/QR, WebSocket, безопасное хранение токена, виртуальная ОС с
независимо добавляемыми приложениями.

## Решение

| Область | Выбор | Обоснование |
|--------|-------|-------------|
| SDK | **Expo SDK 58** (React Native 0.88, выпущен 15.10.2026) | Актуальная стабильная версия. |
| Язык | TypeScript 6.0 (strict) | Общие схемы с `@hs/protocol`. |
| Навигация | **Expo Router** (входит в SDK) | Файловая маршрутизация, поддерживается в Expo Go; оболочка ОС — один маршрут `/os/[appId]`. |
| Состояние | **Zustand 5** | Минимальный API, без провайдеров, удобно тестировать сторы вне React; чистый JS — совместим с Expo Go. |
| Камера/QR | **expo-camera** (`CameraView` + `barcodeScannerSettings`) | Входит в Expo Go; отдельный модуль сканера не нужен. |
| Токен устройства | **expo-secure-store** | Входит в Expo Go; хранение секрета в Keychain/Keystore. |
| Настройки | **@react-native-async-storage/async-storage** | Входит в Expo Go. |
| WebSocket | встроенный `WebSocket` React Native | Без зависимостей. |
| Обратная связь | expo-haptics, expo-audio | Входят в Expo Go. |
| Анимации/глитчи | react-native-reanimated (версия SDK) | Входит в Expo Go. |
| Тесты | jest-expo + @testing-library/react-native | Официальный пресет Expo. |

Все Expo-зависимости устанавливаются **только** через `npx expo install`, чтобы версии соответствовали SDK.

### Ограничения Expo Go (зафиксировано)

- Магазинная версия Expo Go поддерживает **одну** версию SDK. На 30.10.2026 магазинная сборка для
  SDK 58 ожидается «в течение нескольких недель» после 15.10.2026; Android-устройства и эмуляторы
  получают нужную Expo Go через Expo CLI. Задача FND-006 проверяет доступность; если на iOS-устройствах
  её ещё нет, временно используется SDK 57 (React Native 0.86) с обязательным апгрейдом позже.
- Для запуска проекта в Expo Go в режиме разработки требуется вход в Expo-аккаунт
  (`npx expo login`) — участникам нужен бесплатный аккаунт Expo.
- Expo Go не предназначен для релиза: магазинная публикация требует собственной сборки
  (EAS Build / Development Build) — задачи INT-007, REL-002.
- Если понадобится нативный модуль вне Expo Go: (1) зафиксировать в tech-stack.md, (2) искать
  альтернативу из Expo SDK, (3) иначе перейти на Development Build (профиль уже описан в INT-007).
  Архитектура приложения от этого не меняется.

## Последствия

- Нет зависимости от нативного кода вне Expo SDK до INT-007.
- Мобильное приложение импортирует только `@hs/protocol`, но не ядро.
