# 0020. Известная игроку карта в PlayerView

- **Статус:** Proposed
- **Дата:** 2026-11-24
- **Связанные задачи:** PROTO-004
- **Заменяет / заменён:** —

## Контекст

Карта Exploration должна восстанавливаться после переподключения. Клиенту можно показать
посещённые места и выходы из них в пределах уже известных игроку сведений.

## Рассмотренные варианты

1. Хранить карту в Godot. Для переподключения нужна отдельная синхронизация.
2. Передавать карту в полном `PlayerView` по [ADR 0009](0009-protocol-schemas.md).
   Сервер восстанавливает её из истории перемещений, уже входящей в снимок игры.

## Решение

Сервер передаёт `knownMap` с посещёнными локациями и выходами из них. Проекция использует
завершённые перемещения игрока. Схема допускает отсутствие поля в старых снимках
`PlayerView`, а Godot в этом случае продолжает собирать карту по текущей локации.

## Последствия

- Карта восстанавливается при получении полного представления.
- Формат сохранения и его контрольный хеш сохраняются.
- TypeScript-инструменты со строгой схемой обновляются вместе с сервером.
