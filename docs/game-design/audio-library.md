# Аудио-библиотека

Звуки Hollow Signal ([CNT-011](../../tasks/CNT-011.md)): эмбиенты и стингеры Godot-клиента и звуки ОС телефона.
Музыка вне объёма (решение владельца).

## 1. Происхождение и лицензия

Внешних звуковых файлов в проекте нет. Все звуки **синтезируются кодом**: скрипт
[`tools/audio/synth.py`](../../tools/audio/synth.py) (стандартная библиотека Python 3, без зависимостей) строит их из синусоид,
фильтрованного шума и огибающих с фиксированными seed. Повторный запуск даёт те же байты.

| Поле | Значение для всех файлов |
|------|--------------------------|
| Источник | синтез `tools/audio/synth.py`, параметры в функциях скрипта |
| Лицензия | собственная работа проекта, `CC0-1.0` |
| Автор | AI-агент Claude (Anthropic), задача CNT-011, по поручению владельца проекта |
| Чужие сэмплы | нет |

Машинный реестр: [`tools/audio/provenance.json`](../../tools/audio/provenance.json) (путь, роль, где используется, `origin: procedural`,
лицензия, размер, `sha256`). Его пишет `synth.py`; тест `tools/audio/audio-library.test.ts` (в `npm test`) проверяет формат файлов,
пики, стык петель, бюджет и свежесть `sha256`. Если файл заменён вручную (см. раздел 4), запись в реестре обновляют в том же PR.

## 2. Формат и громкость

- WAV, моно, 16 бит, 22050 Гц; суммарно около 3,3 МБ (бюджет 6 МБ).
- Одноразовые звуки нормализованы к пику −3 дБFS, эмбиенты тише (пик около −10 дБFS), клиппинга нет: `synth.py` проверяет пик при каждом запуске.
- Эмбиенты зациклены на 12 с: тоны имеют целое число периодов на петлю, шум подмешан хвостом в начало (равномощный кроссфейд),
  разовые звуки (скрип, капли, стон) целиком внутри петли. Стык проверяется скриптом и тестом.

## 3. Таблица звуков

### Godot-клиент (`apps/desktop/assets/audio/`)

| Файл | Роль | Где используется |
|------|------|------------------|
| `ambient/ambient_bright.wav` | эмбиент: светлое место, тихий гул и сквозняк | `AudioDirector`, `location.lighting = bright` |
| `ambient/ambient_dim.wav` | эмбиент: гул здания, ветер, скрип; запасной | `AudioDirector`, `dim` и неизвестное освещение |
| `ambient/ambient_dark.wav` | эмбиент: низкий дрон, капли, стон конструкций | `AudioDirector`, `dark` |
| `ambient/ambient_night.wav` | эмбиент: холоднее и тише, редкие тоновые стоны | `AudioDirector`, `clock.period = night` |
| `ambient/ambient_boiler.wav` | эмбиент: низкий гул, пульс, стуки труб | `AudioDirector`, локации, в id которых есть `boiler` |
| `stingers/stinger_sanity_drop.wav` | стингер: диссонансный кластер | падение рассудка |
| `stingers/stinger_static_threshold.wav` | стингер: нарастающий шум с треском | Static пересёк 25/50/75 |
| `stingers/stinger_incoming_call.wav` | стингер: расстроенный двухтональный звонок | событие `incomingCall` |
| `stingers/stinger_game_over.wav` | стингер: тяжёлый удар и спад | событие `gameOver` |
| `stingers/stinger_hit.wav` | резкий низкий удар | в библиотеке, пока не подключён |
| `stingers/stinger_heartbeat.wav` | сердцебиение | в библиотеке, пока не подключён |

Выбор эмбиента: котельная (`boiler`) важнее ночи, ночь важнее освещения; высота тона по периоду и месту
по-прежнему задаётся `AudioDirector.ambient_pitch`. Если файла нет, `AudioDirector` синтезирует простую замену и пишет предупреждение.
Импорт: `.wav.import` лежат рядом, PCM без сжатия, у эмбиентов включена петля.

### Телефон (`apps/mobile/assets/audio/`, `src/os/feedback.ts`)

| Файл | Имя в `SOUNDS` | Когда звучит |
|------|----------------|--------------|
| `notify.wav` | `notify` | новое уведомление (не из «Сообщений») |
| `message.wav` | `message` | новое уведомление приложения «Сообщения» |
| `ring.wav` | `ring` | входящий звонок (рингтон 4 с, один раз) |
| `call_end.wav` | `callEnd` | звонок закончился |
| `scan_ok.wav` | `scanOk` | `qr.result` с `ok: true` |
| `error.wav` | `error` | отказ скана или `qr.result` с ошибкой |

Все звуки телефона отключаются настройкой «Звук» (`playSound` ничего не делает при `sound: false`).

## 4. Как заменить звуки

Положите файл с тем же именем (WAV, моно, 16 бит) на место старого, пересоберите импорт Godot
(`godot --headless --path apps/desktop --import`) и обновите запись в `tools/audio/provenance.json` (источник, лицензия, `sha256`).
Для стороннего файла укажите `origin: stock` или `commissioned`, лицензию и автора. Скрипт `synth.py` не запускайте после ручной замены:
он перезапишет файлы. Скромное качество синтеза ожидаемо: это рабочий звуковой ряд, а не финальный.

## 5. Проверка

- Автоматически: `npm test` (`tools/audio/audio-library.test.ts`), `npm run test:godot` (`test_audio_director.gd`: файлы существуют, загружаются,
  петли и выбор варианта), `npm test -w @hs/mobile` (`os-sounds.test.tsx`: звук на событие, тишина при выключенной настройке).
- Вручную (за человеком): послушать эмбиенты на разных локациях и в разное время суток, стингеры, звуки телефона; оценить, что звучит приемлемо
  и не раздражает на петле.
