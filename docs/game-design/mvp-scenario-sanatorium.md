# MVP-сценарий: «Санаторий „Сосновый бор“»

Пресет `sanatorium_winter`. Документ задаёт дизайн; данные — `content/scenarios/sanatorium_winter/`
(задачи CNT-002…CNT-005).

## Завязка

Январь, отдалённый санаторий в сосновом лесу. Метель отрезала дорогу на три дня. Утром в
процедурном корпусе находят тело одного из обитателей санатория. Герой — гость, бывший
следователь, которого администрация просит разобраться до прибытия полиции. Связь с внешним миром —
только через телефон героя, но сигнал… странный.

## Параметры

| Параметр | Значение |
|----------|----------|
| Начало | день 1, 08:00 (дата — `startDateTime` пресета) |
| Длительность | 3 дня (4320 минут); полиция прибывает в конце дня 3 |
| Персонажей | 7 (из пула архетипов: главврач, медсестра, завхоз, повар, гости 3–4 типов) |
| Локаций | 12 (холл, столовая, кабинет врача, процедурная, архив, кухня, котельная, номера ×3, оранжерея, тропа к озеру) |
| Типы инцидентов | `murder` (шаблоны: отравление, удар с инсценировкой падения, «несчастный случай» в котельной) |
| Мотивы (≥ 5 правил) | наследство/деньги, шантаж, ревность, месть за прошлое, сокрытие врачебной ошибки |
| Предыстория | симуляция с дня 0, 08:00 (24 ч до начала игры) |
| Критические события | день 2, 22:00 — отключение электричества (если Static ≥ 50 — раньше); возможный вторичный инцидент |
| Концовки | раскрытие, неполное раскрытие, ложное обвинение, время вышло, гибель, безумие |

## Ограничения на виновника (из пресета, не роли)

- Должен иметь доступ к средству (ядовитое вещество — медкабинет/оранжерея; тяжёлый предмет —
  любой; котельная — ключ у завхоза или украденный ключ).
- Должен иметь окно возможности ≥ 20 минут без свидетелей в месте преступления.
- Должен иметь мотив силы ≥ 0,4 по правилам мотивов (или выполнить правило «сокрытие» при
  наличии секрета, который знает жертва).
- Жертва не может быть виновником (в MVP один виновник, без соучастников).

Любой из 6 оставшихся персонажей, удовлетворяющий ограничениям, может стать виновником;
цель seed sweep — каждый архетип становится виновником хотя бы в 5 % прохождений.

## Обязательная роль телефона в сценарии

- Улики фото (следы, пятна, записи в журнале процедур) — `captureMode: qr`.
- Номера персонажей выдаются в разговорах; гости переписываются с героем.
- Скрытые файлы на «рабочем планшете» медсестры доступны через Files при найденном пароле.
- Static проявляется на телефоне; при отключении электричества заряд телефона становится критичным.
