# MVP-сценарий: «Санаторий „Сосновый бор“»

Пресет `sanatorium_winter`. Документ задаёт дизайн; данные — `content/scenarios/sanatorium_winter/`
(задачи CNT-002…CNT-006).

## Сеттинг (рабочее решение для MVP)

Современность: январь 2026 года, приглушённая «аналоговая» хоррор-эстетика (лампы дневного света,
дисковый телефон без гудка, радио с помехами, советские интерьеры здравницы). Смартфон героя
естественен для этого времени. Это рабочее решение владельца по OQ-12, принятое для CNT-002; от него
зависят `preset.time.startDateTime`, пулы имён, тексты биографий, названия предметов и описания
локаций. Перенос вопроса в «Решённые» в
[open-questions.md](../planning/open-questions.md) делается отдельным изменением.

## Завязка

Январь, отдалённый санаторий в сосновом лесу. Метель отрезала дорогу на три дня. Утром в
процедурном корпусе находят тело одного из обитателей санатория. Герой — гость, бывший
следователь, которого администрация просит разобраться до прибытия полиции. Связь с внешним миром —
только через телефон героя, но сигнал… странный.

## Параметры

| Параметр | Значение |
|----------|----------|
| Начало | день 1, 08:00; `startDateTime` — `2026-01-14T08:00:00` |
| Длительность | 3 дня (4320 минут); полиция прибывает в конце дня 3 |
| Персонажей | 7 из 9 архетипов: 4 сотрудника (главврач, медсестра, завхоз, повар; квота 1..1) и 3 гостя из 5 типов (предприниматель, пенсионер, блогер, отставной офицер, родственник бывшего пациента; квота 0..1) |
| Локаций | 12 (холл, столовая, кухня, кабинет врача, процедурный корпус, архив, котельная, номера первого и второго этажа, мансарда, оранжерея, тропа к озеру); не меньше 2 точек интереса в каждой, всего 37 |
| Типы инцидентов | `murder` (шаблоны: отравление, удар с инсценировкой падения, «несчастный случай» в котельной) |
| Мотивы (≥ 5 правил) | наследство/деньги, шантаж, ревность, месть за прошлое, сокрытие врачебной ошибки |
| Предыстория | симуляция с дня 0, 08:00 (24 ч до начала игры) |
| Критические события | день 2, 22:00 (`at: 2280`) — отключение электричества; если Static ≥ 50 — день 2, 16:00 (`at: 1920`); возможный вторичный инцидент |
| Концовки | раскрытие, неполное раскрытие, ложное обвинение, время вышло, гибель, безумие |

## Ограничения на виновника (из пресета, не роли)

- Должен иметь доступ к средству (ядовитое вещество — медкабинет/оранжерея; тяжёлый предмет —
  любой; котельная — ключ у завхоза или украденный ключ).
- Должен иметь окно возможности ≥ 20 минут без свидетелей в месте преступления.
- Должен иметь мотив силы ≥ 0,4 по правилам мотивов (или выполнить правило «сокрытие» при
  наличии секрета, который знает жертва).
- Жертва не может быть виновником (в MVP один виновник, без соучастников).

Любой из 6 оставшихся персонажей, удовлетворяющий ограничениям, может стать виновником;
цель seed sweep — каждый архетип становится виновником хотя бы в 5 % прохождений.

## Данные пресета (CNT-002)

Минуты в `criticalEvents` и `deadlines` отсчитываются от начала игры (день 1, 08:00).
Пример `at: 2760` в [scenario-presets.md](../procedural-generation/scenario-presets.md) не
соответствует дню 2, 22:00; в данных используется 2280.

| Файл | Содержимое |
|------|------------|
| `locations.json` | 12 локаций, двусторонние связи; запертые переходы: котельная (из кухни и процедурного корпуса, `it_key_boiler`), архив (из кабинета врача, `it_key_archive`). Часы доступа: кухня 06:00–22:00, кабинет врача 08:00–20:00, процедурный корпус 08:00–21:00, оранжерея 07:00–21:00, тропа к озеру 08:00–17:00; сотрудники по своим архетипам — в любое время |
| `items.json` | 35 предметов: яды (`poison`: дигоксин и морфин в шкафу медикаментов, средство от вредителей и олеандр в оранжерее), тяжёлые предметы (`heavy`, 6 штук), физические ключи, журналы, планшет медсестры и стикер с паролем |
| `archetypes.json` | 9 архетипов, по 8 имён и 8 фрагментов биографии на каждый (72 имени, 72 фрагмента); распорядок покрывает сутки без пропусков и пересечений |
| `relationships.json` | 13 шаблонов отношений с типами из `RelationType`, 18 видов секретов |

Правила данных:

- Ключи — физические предметы (ADR 0016 «Физические ключи для запертых переходов», вносится PR #34):
  ключ котельной у завхоза, ключ архива у главврача. `access` архетипа не создаёт владения.
- У каждого предмета ровно одно начальное размещение. `ownerArchetype` указывают только для
  архетипов с квотой `min ≥ 1`: иначе владелец может отсутствовать в составе, и `ItemRegistry`
  отклонит размещение.
- Предмет, лежащий в локации, указан в `itemIds` точки интереса этой локации.
- Биографии написаны без рода (нет прошедшего времени и кратких прилагательных о самом
  персонаже), потому что имена в пулах обоих родов, а поля пола в схеме нет. Исключение —
  медсестра: пул имён женский по названию архетипа.
- Виды секретов: `will_changed`, `affair`, `embezzlement`, `malpractice`, `falsified_records`,
  `hidden_debt`, `gambling_debt`, `false_identity`, `past_conviction`, `drug_theft`, `addiction`,
  `illegitimate_child`, `terminal_diagnosis`, `insurance_fraud`, `blackmail_material`,
  `hit_and_run`, `secret_investigation`, `land_deal`. Шаблоны `secret_<kind>` ссылаются на тексты
  CNT-005; загрузчик эти ссылки не проверяет.
- Ни один архетип, тег или поле не обозначает виновника или подозреваемого.

### Временный каркас для загрузчика

Загрузчик требует все девять корневых файлов, а `crossCheck` — существующие шаблоны инцидентов и
правила следов для их глаголов. Поэтому CNT-002 содержит минимальные согласованные данные
`motives.json` (5 правил), `crimes.json` (3 шаблона), `trace-rules.json` (11 правил для `take`,
`poison`, `strike`, `tamper`, `stage`, `hide`, `destroy`) и `deduction-rules.json` (4 правила).
Это каркас, а не результат CNT-003/CNT-004: требования, планы, силы мотивов, следы и правила
дедукции будут пересмотрены там. Правила следов используют только `$location` в `at` и
глаголы формата `verbSchema`, совместимые с EVD-001.

## Обязательная роль телефона в сценарии

- Улики фото (следы, пятна, записи в журнале процедур) — `captureMode: qr`.
- Номера персонажей выдаются в разговорах; гости переписываются с героем.
- Скрытые файлы на «рабочем планшете» медсестры доступны через Files при найденном пароле.
- Static проявляется на телефоне; при отключении электричества заряд телефона становится критичным.
