| OQ-14 | Контракт закона сохранения улик и уничтожения следов | EVD-001 требует `EVIDENCE_RULE_INVALID` для сокрытия без вторичного следа, но не определено: какие глаголы считаются сокрытием (`hide`/`destroy`/`stage`, а также `move` из `ConcealEvidence`?); что считается вторичным следом на уровне правил (любое правило глагола, правило без `when`, покрытие каждого возможного предмета?); обязан ли каждый сценарий (включая `_test_minimal`) иметь правила для этих глаголов; какое событие и по какому признаку заполняет `Trace.destroyedBy` (предмет-носитель, локация, шаблон) | EVD-001 (критерий «правило без вторичного следа → EVIDENCE_RULE_INVALID»), SIM-005, CNT-004 | Сокрытие = `hide`/`destroy`/`stage`; для каждого из них в сценарии обязательно хотя бы одно правило без `when`; `destroyedBy` выставляется событию `destroy`, цель которого совпадает с `Trace.itemId` |

| OQ-16 | Временные границы следа | Не зафиксировано: `availableFrom` = `t` или `t + duration` события; от чего отсчитывается `decaysAfter`; открыт ли интервал `[availableFrom, decaysAt)`; различаются ли `decaysAfter: null` и отсутствие поля; допустим ли `decaysAfter: 0` | EVD-001, EVD-002 (`discoverable`) | `availableFrom = t + duration` (по инварианту 3, реализовано предварительно), `decaysAt = availableFrom + decaysAfter`, интервал полуоткрытый как `Interval`, `null` ≡ отсутствие поля, `0` запрещён схемой |
| OQ-17 | Гранулярность сопоставления правил следов | Реализовано: правило срабатывает один раз на событие, `when` проверяется только по целям вида `item`, в `at` допускается только `$location`. Не решено: порождать ли следы на каждый подходящий предмет при нескольких целях; должен ли `targetTag` совпадать с тегами локаций; нужны ли другие подстановки в `at` | EVD-001, CNT-004 | Оставить реализованное поведение; расширять по запросу контента CNT-004 |
