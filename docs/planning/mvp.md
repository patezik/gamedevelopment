# MVP — минимальный игровой продукт

**Главный критерий успеха:** игрок может пройти полноценное сгенерированное расследование, в
котором мобильный телефон — необходимая часть игрового процесса.

## 1. Состав MVP

| Требование | Как обеспечивается | Задачи |

| Один полноценный сценарий | «Санаторий „Сосновый бор“», 3 игровых дня | CNT-002…007 |
| Несколько генерируемых персонажей | 7 персонажей из ≥ 8 архетипов | GEN-003, GEN-004 |

## 2. Сознательно вне MVP

Второй сценарий, соучастники, финальный арт и аудио (плейсхолдеры допустимы), встроенный сервер
в сборке игры (в MVP сервер запускается командой), локализация, Maestro E2E, магазинные сборки,
TLS, мета-прогрессия.

## 3. Критерии приёмки MVP (веха M7)

1. Новый игрок по `docs/development/setup.md` запускает сервер, Godot-клиент и приложение в Expo Go.
2. Привязка телефона по QR занимает < 30 секунд в типичной домашней сети.
3. Расследование проходится от начала до концовки `solved` человеком (INT-003) и ботом (INT-002).
4. В каждом сгенерированном расследовании ≥ 30 % обязательных улик собираются только камерой
   телефона (V-PHONE-REQUIRED), а контакты и сообщения NPC существуют только в телефоне.
5. Seed sweep 1000: неудачи < 1 %, энтропия виновников ≥ 0,8·max, каждый архетип — виновник ≥ 5 %.
6. Одинаковые seed + действия дают одинаковое состояние (V-DETERMINISM, тесты replay).
7. Достижимы все 6 концовок.
8. Приложение не запрашивает никаких разрешений, кроме камеры.
9. Нет известных блокирующих багов; найденные проблемы оформлены задачами.

## 4. Оценка объёма

121 задача фаз 1–7 из 140 (см. [tasks/INDEX.md](../../tasks/INDEX.md)). При 4–6 параллельно
работающих агентах и средней длительности задачи 0,5–2 дня агентской работы критический путь
(23 задачи до M7: Foundation → схемы контента → истина → конвейер генерации → сервер → привязка →
плейтест) определяет срок сильнее, чем общий объём. Ускорить MVP можно только сокращением этой цепочки.
