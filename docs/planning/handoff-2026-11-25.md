## Рабочие приёмы, которые сэкономят время

- Конфликты `tasks/INDEX.md` возникают постоянно из-за claim-коммитов. Для PR с конфликтом только в
  индексе: взять свежий `origin/main`, применить изменения ветки без `tasks/INDEX.md`, выполнить
  `npm run tasks:index`, запушить в ветку PR и смержить сразу, не ожидая нового CI (код не менялся).
- Тесты должны быть лёгкими: тяжёлый property-тест GEN-009 вплотную подвёл джоб к лимиту.
- Ревью каждого PR делает не автор; к ревью агентов относиться как к проверке, а не гарантии:
  часть настоящих ошибок (утечка id галлюцинаций, неверные падежи в текстах) нашли только при чтении.
