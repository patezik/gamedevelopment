# Глоссарий

| Термин | Идентификатор | Значение |
|--------|---------------|----------|
| Персонаж | `Character` | Участник мира сценария. Не имеет роли «подозреваемый». |
| Виновник | `IncidentRecord.culpritIds` | Фактический виновник прохождения; известен только серверу. |
| Подозреваемый | `PlayerKnowledge.suspicions` | Персонаж, которого отметил подозреваемым **игрок**. |
| Персона интереса | `PersonOfInterest` | Персонаж, связанный хотя бы с одной найденной игроком уликой (подсказка UI). |
| Сценарий-пресет | `ScenarioPreset` | Шаблон: мир, правила, ограничения, концовки; без виновника. |
| Расследование | `Investigation` | Сгенерированный экземпляр: мир, персонажи, истина, улики, политики лжи. |
| Истина | `TruthModel` | Объективный журнал событий и запись инцидента. |
| Событие истины | `TruthEvent` | Действие, совершённое в мире (NPC или игроком). |
| Факт / пропозиция | `Fact` / `Proposition` | Типизированное утверждение о мире. |
| Убеждение | `Belief` | Пропозиция, которую персонаж считает верной (может ошибаться). |
| Политика лжи | `LiePolicy` | Что персонаж скрывает и что выдумывает. |
| Показание | `Statement` | Утверждение персонажа игроку; на сервере помечено правдой/ошибкой/ложью. |
| След | `Trace` | Материальное/документальное/цифровое/свидетельское последствие события. |
| Улика | `Clue` | След, который игрок может обнаружить; поддерживает утверждения. |
| Утверждение | `Claim` | Элемент дедукции: мотив, средство, возможность, присутствие, алиби, противоречие. |
| Дело | `CaseFile` | Обвинение игрока с приложенными уликами. |
| Игровые минуты | `GameMinutes` | Целое число минут от начала сценария. |
| Помехи | `static` | Глобальная эскалация 0–100, искажающая телефон и рассудок. |
| Представление | `PlayerView` / `PhoneView` | Проекция знаний игрока для клиента; без истины. |
| Seed sweep | `hs-sweep` | Массовая генерация и валидация расследований. |
| QR привязки | `hs1:pair:…` | Подключение телефона к сессии. |
| QR улики | `hs1:ev:…` | Игровой токен фиксации улики камерой телефона. |
| QR Expo Go | `exp://…` | Только для разработки: загрузка JS-бандла в Expo Go. |
