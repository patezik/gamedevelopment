# Видение проекта

**Рабочее название:** Hollow Signal («Пустой сигнал»). Название не окончательное — см.
[open-questions.md](../planning/open-questions.md) (OQ-05).

## Одной фразой

Детективный survival horror roguelike, в котором каждое прохождение — новое логически
непротиворечивое расследование, а реальный смартфон игрока становится телефоном следователя:
через него собираются улики, приходят сообщения от свидетелей и звонят те, кто звонить не должен.

## Ключевые столпы

1. **Расследование, которое можно решить логикой.** Истина каждого прохождения существует
   объективно и проверена автоматически. Игрок не угадывает — он доказывает.
2. **Любой может оказаться виновником.** Нет списка подозреваемых. Персонажи — полноценные
   участники мира со своими биографиями, секретами и планами; виновником становится тот, у кого в
   этом мире сложились мотив, средства и возможность.
3. **Мир живёт без игрока.** Персонажи двигаются по расписаниям, встречаются, лгут, прячут
   улики. Пока игрок тратит время на одно, где-то происходит другое.
4. **Время — главный ресурс.** Каждое действие стоит игровых минут. Сценарий конечен,
   угроза растёт, улики исчезают.
5. **Телефон в руке — часть игры.** Камера телефона фиксирует улики с экрана, в телефоне живут
   контакты, переписки, фото и файлы расследования. Без телефона расследование не пройти.
6. **Психологический хоррор через неопределённость.** Рассудок героя влияет на восприятие:
   странные уведомления, искажённые фото, звонки с неизвестных номеров. Страх рождается из
   сомнения в собственных данных, а не только из монстров.

## Отличие от источников вдохновения

World of Horror вдохновляет атмосферой мрачного, ограниченного ресурсами расследования. Наш проект
отличается в основе:

| Аспект | Hollow Signal |
|--------|---------------|
| Тайны | Генерируются из модели истины и симуляции персонажей; решаются дедукцией |
| Персонажи | Автономные агенты с субъективными знаниями, ложью и памятью |
| Подозреваемые | Не существуют как роль; формируются из знаний игрока |
| Время | Единые игровые часы, расписания NPC, пропускаемые события |
| Интерфейс | Два экрана: компьютер (мир) + реальный смартфон (виртуальная ОС героя) |
| Глобальная угроза | «Помехи» (Static) — нарастающий сигнал, искажающий телефон и рассудок |

## Целевая аудитория и платформы

- Игроки детективных и хоррор-roguelike игр, любители дедукции (ПК + смартфон).
- Desktop: Windows (основная), Linux, macOS — Godot 4.7.
- Mobile: Android и iOS — companion-приложение на Expo.
- Одиночная игра; оба устройства в одной локальной сети.

## Критерий успеха MVP

Игрок может пройти полноценное сгенерированное расследование от начала до одного из исходов,
причём телефон необходим: часть улик собирается только камерой телефона, а ключевые контакты и
сообщения существуют только в нём. Подробно — [mvp.md](../planning/mvp.md).

## Что мы сознательно не делаем

- Мультиплеер, онлайн-сервисы, аккаунты игроков.
- Доступ к реальным данным телефона (контакты, SMS, фото игрока) — никогда.
- Генерация текста языковыми моделями во время игры (тексты — из шаблонов; вопрос пересматривается
  после MVP, OQ-06).
- Открытый 3D-мир: представление — статичные иллюстрированные локации с интерактивными точками.
