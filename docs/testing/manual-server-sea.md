# Ручная проверка встроенного сервера — INT-005 / PR #68

До успешного завершения проверки критерий «чистая Windows + привязка телефона» в INT-005 не
отмечается, PR #68 не сливается. Проверка на компьютере разработчика (Node.js установлен, окна
брандмауэра уже разрешены) её не заменяет.

## Подготовить заранее

- Собрать Windows x64 пакет из одного коммита PR: настоящий экспорт Godot (официальные шаблоны
  экспорта 4.7.2) и SEA (`npm run build -w @hs/server`).
- Рядом с exe игры: её pck и каталог `server` с `hollow-signal-server.exe` и `content/scenarios`.
  В пакет не входят исходники, `node_modules`, сохранения и пользовательские данные.
- Перенести пакет на Windows без установленного Node.js, npm, Git и Godot.
- Companion в Expo Go на физическом телефоне. Компьютер игры и телефон — в одной сети. Metro
  работает на компьютере разработчика; если проверяющий в другой сети, Metro раздаётся через
  `npx expo start --tunnel` (только Metro, Session Server игры остаётся в локальной сети проверяющего).

## Действия и ожидаемый результат

1. Запустить игру без ручного запуска сервера. Должен появиться сценарий санатория.
2. Отключить случайный seed, ввести 2 и создать дело. Должен открыться экран с игровым QR.
3. Выбрать Wi-Fi-адрес компьютера игры, а не localhost или VPN-адрес.
4. Внутри companion отсканировать игровой QR. QR Expo Go используется только для загрузки приложения.
5. Убедиться, что телефон подключён и кнопка «Начать расследование» открывает игровой экран.
6. Закрыть игру обычным способом. Процесс hollow-signal-server.exe должен исчезнуть.
7. Запустить снова, принудительно завершить только процесс игры через Диспетчер задач.
   Сервер должен исчезнуть самостоятельно в течение примерно четырёх секунд.
8. Если порт 7420 занят, проверить выбор следующего свободного из 7420–7439 и привязку на фактическом порту.

До шага 4 открыть на телефоне `http://АДРЕС:ПОРТ/api/v1/health` (адрес и порт — с экрана
привязки): ожидается `status: ok`. Если не открывается — брандмауэр или сеть, см.
[setup.md, «Брандмауэр Windows для встроенного сервера»](../development/setup.md#брандмауэр-windows-для-встроенного-сервера).
Не отключать брандмауэр целиком и не разрешать общедоступные сети; доступ в частной сети разрешает
сам проверяющий. Сохранить лог игры (`%APPDATA%\Godot\app_userdata\Hollow Signal\logs\godot.log`)
и точное сообщение ошибки.

## Зафиксировать результат

- Коммит сборки, версия Windows, отсутствие Node.js, модель iPhone и iOS.
- Загрузка сценариев, создание дела, привязка телефона и переход в расследование.
- Завершение сервера после обычного и принудительного выхода.
- Выбор свободного порта, если этот случай проверялся.
- Что не прошло или не проверялось — отдельным списком, без отметки задачи done.

После успешной проверки обновить критерии INT-005 и статус перед squash merge.
Если обнаружена ошибка — сначала исправление и повторная проверка, затем слияние.
