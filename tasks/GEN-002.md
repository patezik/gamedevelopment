# GEN-002 — Стадия WorldGen: локации, предметы, варианты из пресета

## Описание

Первая стадия: конкретный мир из шаблона.

## Цель

Каждый seed даёт конкретный вариант мира в рамках пресета.

## Scope

- Инстанцирование локаций и связей; выбор вариантов (запертые двери, размещение предметов по spawn-правилам).
- WorldState для последующих стадий.

## Out of Scope

- Персонажи.

## Зависимости

- [GEN-001](GEN-001.md) — Каркас конвейера генерации: стадии, подпотоки, отчёт, GENERATOR_VERSION
- [WORLD-002](WORLD-002.md) — Предметы, контейнеры и история их перемещений

## Затрагиваемые модули

- `packages/generator/src/stages/world-gen.ts`

## Ожидаемый результат

Стадия WorldGen.

## Критерии приёмки

- [ ] Все локации связны (граф достижим из стартовой локации).
- [ ] Golden-тест для 3 seed на _test_minimal.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Unit + property: связность для 500 seed.
