# INV-002 — Утверждения (Claims) и правила дедукции

## Описание

Игрок доказывает мотив, средство и возможность через утверждения (investigation-model.md §3).

## Цель

Формальная модель того, что игрок может считать установленным.

## Scope

- Claim-типы: presence, opportunity, means, motive, alibi, contradiction.
- Интерпретатор deduction-rules.json.
- evaluateClaims(playerKnowledge) → EstablishedClaim[] с цепочкой поддержки.
- Использует известное игроку окно инцидента.

## Out of Scope

- Противоречия (INV-004), обвинение (INV-005).

## Зависимости

- [INV-001](INV-001.md) — PlayerKnowledge: найденные улики, услышанные показания, контакты, журнал

## Затрагиваемые модули

- `packages/core/src/investigation/claims.ts`

## Ожидаемый результат

Модуль утверждений.

## Критерии приёмки

- [ ] Каждое EstablishedClaim объясняется списком улик/показаний.
- [ ] Модуль не читает истину.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Unit на tiny-manor: полный набор улик устанавливает M/M/O виновника.
