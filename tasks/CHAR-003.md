# CHAR-003 — Расписания и рутины: whereShouldBe, переопределения

## Описание

Персонажи живут по расписаниям; расписания должны покрывать весь сценарий (character-simulation.md).

## Цель

Для любого персонажа и момента известно, где он должен быть по плану.

## Scope

- RoutineBlock { from, to, location, activity, flexibility } в минутах суток, повторяемые по дням.
- ScheduleOverride (изгиб расписания генератором или симуляцией).
- whereShouldBe(c, t, overrides).
- Проверка покрытия: CHAR_SCHEDULE_GAP.

## Out of Scope

- Исполнение расписаний симуляцией (SIM-001).

## Зависимости

- [CHAR-001](CHAR-001.md) — Модель персонажа: личность, биография, цели, страхи, доступы
- [WORLD-001](WORLD-001.md) — Граф локаций: перемещения, освещение, доступ по часам и замкам

## Затрагиваемые модули

- `packages/core/src/characters/schedule.ts`

## Ожидаемый результат

Модуль расписаний.

## Критерии приёмки

- [ ] Ночные блоки, переходящие через полночь, поддерживаются.
- [ ] Override имеет приоритет над рутиной.
- [ ] Дыра в расписании — ошибка валидации.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Unit: табличные; property: покрытие 24 ч для сгенерированных рутин.
