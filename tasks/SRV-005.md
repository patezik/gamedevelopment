# SRV-005 — Рассылка представлений и событий с фильтром по роли

## Описание

После каждого изменения клиенты получают актуальные представления (overview.md §3).

## Цель

Desktop и телефон всегда синхронизированы с состоянием сессии.

## Scope

- После dispatch: stateVersion++, view.update для каждой роли, события с видимостью роли.
- action.result отправителю.
- Кэш последнего view для resync.

- —

Рассылка представлений.
