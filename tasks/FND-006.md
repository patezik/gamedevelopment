# FND-006 — Bootstrap apps/mobile: Expo SDK 58, Expo Router, TypeScript, jest-expo

## Описание

Companion-приложение (ADR 0007) должно запускаться в Expo Go и импортировать @hs/protocol из монорепозитория.

## Цель

Пустое приложение запускается на реальном телефоне через Expo Go и показывает экран-заглушку.

## Scope

- Проверить доступность Expo Go для SDK 58 в App Store/Google Play. Если для iOS-устройств её нет — использовать SDK 57 и записать это в tech-stack.md и ADR 0007 (раздел «Ограничения»).
- npx create-expo-app с шаблоном default для выбранного SDK в apps/mobile, имя пакета @hs/mobile.
- Expo Router, TypeScript strict, удалить демо-экраны шаблона.
- Подключить @hs/protocol (workspace) и проверить, что Metro его резолвит.
- jest-expo + @testing-library/react-native, один smoke-тест.
- app.json: имя, slug, разрешения — только камера (описание использования на русском).

## Out of Scope

- Виртуальная ОС (MOB-001).
- Привязка (MOB-002).

## Зависимости

- [FND-001](FND-001.md) — Корневой TypeScript-тулчейн: TS 6, ESLint 10, Prettier, Vitest 5
- [FND-004](FND-004.md) — Пакет @hs/protocol: конверт, ErrorCode, версия, экспорт JSON Schema

## Затрагиваемые модули

- `apps/mobile`

## Ожидаемый результат

npm run start -w @hs/mobile открывает приложение в Expo Go; экран показывает PROTOCOL_VERSION из @hs/protocol.

## Критерии приёмки

- [ ] Запуск в Expo Go на Android и iOS проверен вручную (отметка в PR со скриншотами).
- [ ] npm test -w @hs/mobile проходит.
- [ ] В app.json нет разрешений, кроме камеры.
- [ ] Версия SDK зафиксирована в tech-stack.md.
- [ ] `npm run tasks:check` и проверки CI зелёные.
