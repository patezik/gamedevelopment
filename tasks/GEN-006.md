# GEN-006 — Стадия IncidentSelection: жертва, шаблон, виновник из всех допустимых

## Описание

Ключевое требование: виновник выбирается из всех участников мира по выполнимости, без списка подозреваемых (generation-pipeline.md §3).

## Цель

Любой подходящий персонаж может стать виновником.

## Scope

- Алгоритм из generation-pipeline.md §3: feasibility (motive, means, opportunity, capable) для каждого c ≠ v.
- Взвешенный выбор score^γ, γ из пресета (дефолт 0.7).
- IncidentPlan; feasibleCulpritCount в отчёте.
- Ошибка при пустом feasible для всех жертв → попытка регенерации.

## Out of Scope

- Детальный план действий (GEN-007).
- Соучастники (GEN-012).

## Зависимости

- [GEN-005](GEN-005.md) — Стадия ConflictGen: правила мотивов для всех пар персонажей
- [GEN-002](GEN-002.md) — Стадия WorldGen: локации, предметы, варианты из пресета

## Затрагиваемые модули

- `packages/generator/src/stages/incident-selection.ts`

## Ожидаемый результат

Стадия выбора инцидента.

## Критерии приёмки

- [ ] В коде и данных нет понятия suspect.
- [ ] На _test_minimal за 2000 seed виновником становится каждый персонаж, удовлетворяющий ограничениям, хотя бы раз.
- [ ] Жертва никогда не виновник.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Property: выбранный виновник всегда удовлетворяет feasibility.
- Статистический тест распределения.
