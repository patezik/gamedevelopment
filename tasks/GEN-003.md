# GEN-003 — Стадия CastGen: персонажи из архетипов, личность, биография, имена

## Описание

Персонажи — полноценные участники мира (генерация без ролей в преступлении).

## Цель

Разнообразные, внутренне согласованные персонажи.

## Scope

- Квоты архетипов из пресета.
- Личность — сэмпл распределений архетипа (усечённое нормальное, детерминированное).
- Биография из тегированных фрагментов с исключениями (несовместимые теги).
- Имена из пулов без повторов фамилий/имён внутри расследования.
- Рутина архетипа с вариацией по личности; доступы.

## Out of Scope

- Отношения и секреты (GEN-004).

## Зависимости

- [GEN-001](GEN-001.md) — Каркас конвейера генерации: стадии, подпотоки, отчёт, GENERATOR_VERSION
- [CHAR-001](CHAR-001.md) — Модель персонажа: личность, биография, цели, страхи, доступы
- [CHAR-003](CHAR-003.md) — Расписания и рутины: whereShouldBe, переопределения

## Затрагиваемые модули

- `packages/generator/src/stages/cast-gen.ts`

## Ожидаемый результат

Стадия CastGen.

## Критерии приёмки

- [ ] Квоты соблюдены для 1000 seed.
- [ ] Нет дубликатов имён.
- [ ] Рутины покрывают сутки (CHAR_SCHEDULE_GAP не возникает).
- [ ] `npm run tasks:check` и проверки CI зелёные.

- Property-тесты на 1000 seed.
