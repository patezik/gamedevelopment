# CNT-003 — MVP-сценарий: шаблоны преступлений и правила мотивов

## Описание

Три шаблона инцидента и ≥ 5 правил мотивов.

Уточнение приёмки: критерий «feasible-виновник на 90 % из 500 seed» требует стадий SocialGen,
ConflictGen и IncidentSelection (GEN-004…GEN-006), которых в `main` пока нет. В CNT-003 он
заменён статической проверкой выполнимости на уровне архетипов; проверка на 500 seed
сгенерированных миров переносится на момент готовности GEN-006 (см. «Перенесено»).

## Цель

Генератор может строить разнообразные инциденты MVP.

## Scope

- crimes.json: poisoning, staged_fall, boiler_accident — требования, планы, окна.
- motives.json: inheritance, blackmail, jealousy, revenge, malpractice_coverup (+ опционально debt).
- Каждое правило ссылается на существующие типы отношений/секретов.

## Out of Scope

- Следы (CNT-004).

## Зависимости

- [CNT-002](CNT-002.md) — MVP-сценарий: локации, предметы, архетипы, отношения (данные)

Данные преступлений и мотивов.

## Критерии приёмки

- [x] content:check зелёный.
- [x] Статическая проверка (`sanatorium-incidents.test.ts`): для каждого шаблона в каждом из 10
  возможных составов найдётся жертва хотя бы с одним выполнимым виновником (мотив, средство,
  личность, окно без свидетелей); каждый архетип выполним как виновник хотя бы в одном шаблоне.
- [x] Глаголы планов покрыты правилами следов для своих целей; мотивы ссылаются на существующие
  типы отношений и секреты одного шаблона отношений.
- [x] `npm run tasks:check` и проверки CI зелёные.

## Перенесено

- Для каждого шаблона найдётся хотя бы один feasible-виновник на 90 % из 500 seed. Требует
  GEN-006 (IncidentSelection) и предшествующих стадий; в CNT-003 не проверено. Выполняется
  seed sweep пресета `sanatorium_winter` после GEN-006.

## Требования к тестированию

- content:check; статический тест `sanatorium-incidents.test.ts`; тест GEN-006 на пресете — после GEN-006.
