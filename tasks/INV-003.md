# INV-003 — Персоны интереса и отметки подозрений игрока

## Описание

Suspect — производное от знаний игрока, а не роль (investigation-model.md §1).

## Цель

Доска дела показывает связанных персонажей, а игрок сам решает, кого подозревать.

## Scope

- personsOfInterest(pk) с причинами связи.
- Действие markSuspicion(characterId, level, note) — без затрат времени.

## Out of Scope

- UI доски (GDT-008).

## Зависимости

- [INV-002](INV-002.md) — Утверждения (Claims) и правила дедукции

## Затрагиваемые модули

- `packages/core/src/investigation/suspicion.ts`

## Ожидаемый результат

Модуль подозрений.

## Критерии приёмки

- [ ] Персона интереса появляется только после улики/показания, связанного с персонажем.
- [ ] Модуль не читает истину.
- [ ] `npm run tasks:check` и проверки CI зелёные.
