# REL-005 — HTTP/WS в LAN в release-сборке Android (cleartext traffic)

## Описание

Найдено в REL-003. Приложение подключается к Session Server по `http://` (привязка) и `ws://`
(игра) — `apps/mobile/src/pairing/pairClient.ts`, `apps/mobile/src/connection/WsClient.ts`.
По `npx expo config --type introspect` основной манифест Android не содержит
`android:usesCleartextTraffic="true"` и network security config. На Android 9+ (target SDK ≥ 28)
release-сборка по умолчанию запрещает незашифрованный трафик. Debug-сборки и Expo Go это не
затрагивает. Значит, привязка в release-сборке Android, вероятно, не работает. В реальной
release-сборке это не проверялось.

На iOS Expo по умолчанию ставит `NSAllowsArbitraryLoads: true`, поэтому этот вопрос касается только
Android.

## Цель

Release-сборка Android подключается к игре в LAN по HTTP/WS, пока не реализован TLS по ADR 0018.

## Scope

- Проверить поведение на release-сборке Android (APK через `expo run:android --variant release`
  или EAS).
- Если проблема подтвердится — разрешить cleartext-трафик минимально: предпочтительно через network
  security config, а не глобально. Способ (`expo-build-properties` или свой config plugin) выбрать с
  учётом правила о зависимостях (tech-stack.md).
- Обновить раздел «Шифрование» в docs/legal/privacy-policy.md, если изменится модель.

## Out of Scope

- TLS и pinning (ADR 0018).
- Публикация в Google Play (решение владельца, OQ-10).
