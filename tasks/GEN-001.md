# GEN-001 — Каркас конвейера генерации: стадии, подпотоки, отчёт, GENERATOR_VERSION

## Описание

Генерация — последовательность чистых стадий (ADR 0006, generation-pipeline.md §2).

## Цель

Стадии добавляются независимо, каждая со своим подпотоком RNG и замером времени.

## Scope

- Интерфейс Stage<I,O>, GenerationContext (rng.fork("gen/"+name), content, logger).
- runPipeline(stages, input) с замером времени стадий.
- GenerationReport (без утечек наружу).
- GENERATOR_VERSION = "0.1.0".
- Механизм попыток: attempt N использует seed "<seed>#N".

## Out of Scope

- Конкретные стадии (GEN-002…GEN-010).
- Интеграция валидатора (GEN-011).

## Зависимости

- [CORE-001](CORE-001.md) — Детерминированный PRNG sfc32 с подпотоками fork(label)
- [CNT-001](CNT-001.md) — Схемы контента сценариев (zod) и загрузчик @hs/core/content
- [CORE-003](CORE-003.md) — Тип Investigation и fixture-builder мини-сценария «tiny-manor»

## Затрагиваемые модули

- `packages/generator/src/pipeline`

## Ожидаемый результат

Каркас конвейера с тестовыми стадиями.

## Критерии приёмки

- [ ] Добавление стадии не меняет выход предыдущих стадий для того же seed (тест).
- [ ] Отчёт содержит время каждой стадии.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Unit с фиктивными стадиями.
