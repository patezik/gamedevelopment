# SRV-001 — SessionManager: сессии, очередь действий, жизненный цикл

## Описание

Сервер хостит GameEngine на сессию и сериализует действия (backend.md §4).

## Цель

Действия двух клиентов исполняются строго по одному, состояние сессии управляемо.

## Scope

- Session { id, engine, stateVersion, eventSeq, eventBuffer(200), tokens (хеши), status }.
- Очередь действий (Promise-цепочка) на сессию.
- Состояния created/active/suspended/finished/disposed и TTL.
- Интерфейс InvestigationProvider (реализация через генератор в SRV-002).

## Out of Scope

- REST и WS.

## Зависимости

- [FND-005](FND-005.md) — Каркас apps/server: Fastify 5, конфигурация, /health, логирование
- [ENG-001](ENG-001.md) — GameEngine: агрегат состояния, dispatch, действия move и wait

## Затрагиваемые модули

- `apps/server/src/sessions`

## Ожидаемый результат

Менеджер сессий.

## Критерии приёмки

- [ ] Конкурентные dispatch из двух источников исполняются последовательно (тест с задержками).
- [ ] faulted при исключении движка, клиенты получают INTERNAL.
- [ ] `npm run tasks:check` и проверки CI зелёные.
