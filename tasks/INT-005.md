# INT-005 — Упаковка сервера в исполняемый файл (Node SEA) и запуск из Godot

## Описание

В релизе игрок не должен устанавливать Node.js (ADR 0002, риск R-03).

Блокировка: по решению владельца от 26.11.2026 ручная проверка на чистой Windows с физическим телефоном отложена до последнего часа перед сдачей. До подтверждения этого критерия задача не завершена, PR #68 не сливается. Проверка на компьютере разработчика с PATH без Node.js не заменяет чистую Windows. Порядок проверки сохранён в docs/testing/manual-server-sea.md. Перед проверкой нужно пересобрать пакет из актуального коммита PR; подготовленная локальная сборка относится к 49eb1cf6c22bec0e6d438525bf5ae8448d1e1918.

## Цель

Godot-игра запускает встроенный сервер и подключается к нему.

## Scope

- Сборка сервера (бандл + Node.js Single Executable Application) для Windows, Linux, macOS.
- ServerLauncher: запуск дочернего процесса, ожидание /health, завершение при выходе.
- Свободный порт при занятости 7420.
- Подпись/нотаризация — отдельный вопрос (OQ-09).

## Out of Scope

- Экспорт Godot (REL-001).

## Критерии приёмки

- [ ] Godot-сборка на чистой Windows-машине без Node.js проходит привязку телефона.
  На Windows SEA из отдельного рабочего каталога проверены health, каталог сценариев, создание дела seed 2 и POST /pair. Встроенный сервер получает штатные игровые сервисы и каталог content/scenarios рядом с exe. Проверка готовой Godot-сборки на чистой Windows с физическим телефоном остаётся невыполненной.
- [x] Процесс сервера завершается вместе с игрой. На Linux проверены `OS.kill` при выходе
  и `HS_PARENT_PID` при падении игры. Windows SEA отвечает на health и завершается при
  остановке процесса, указанного в `HS_PARENT_PID`.
- [x] `npm run tasks:check` и проверки CI зелёные: run 45852870465, включая SEA-сборку и smoke на Windows, Linux и macOS. Последующие изменения в этом коммите — только документация и статус задачи.
