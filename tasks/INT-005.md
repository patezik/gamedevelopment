# INT-005 — Упаковка сервера в исполняемый файл (Node SEA) и запуск из Godot

## Описание

В релизе игрок не должен устанавливать Node.js (ADR 0002, риск R-03).

Работа передана 26.11.2026 от claude-w5 (Timofey10012) агенту egor-claude-int-005 по согласованию в PR #68; claim в `main` переназначен коммитом `4c0d2d2`. Внешняя ручная проверка на чистой Windows выполнена 27.11.2026 по архиву `HollowSignal-INT-005-9229c4b-win64.zip` (сборка из коммита `9229c4b6740b26cbcc3aab0fc2cda7234a3c267e`), результат — в критериях приёмки и PR #68.

## Цель

Godot-игра запускает встроенный сервер и подключается к нему.

## Scope

- Сборка сервера (бандл + Node.js Single Executable Application) для Windows, Linux, macOS.
- ServerLauncher: запуск дочернего процесса, ожидание /health, завершение при выходе.
- Свободный порт при занятости 7420.
- Подпись/нотаризация — отдельный вопрос (OQ-09).

## Out of Scope

- Экспорт Godot (REL-001).

## Критерии приёмки

- [x] Godot-сборка на чистой Windows-машине без Node.js проходит привязку телефона.
  27.11.2026 участник команды проверил автономный архив `HollowSignal-INT-005-9229c4b-win64.zip`
  (настоящий экспорт Godot 4.7.2 + SEA из коммита `9229c4b`, SHA-256 архива
  `e7e2f141be9959da0d30ea1a9f188dae3e572363add2548b812d275fab394df3`) на чистой Windows с
  физическим iPhone; по его сообщению всё работает. Логи и скриншоты не передавались, результат зафиксирован со
  слов проверяющего. До этого на машине разработчика: пакет при занятом 7420 поднял сервер на
  7421, физический iPhone привязался по Wi-Fi.
- [x] Процесс сервера завершается вместе с игрой. На Linux проверены `OS.kill` при выходе
  и `HS_PARENT_PID` при падении игры. Windows SEA отвечает на health и завершается при
  остановке процесса, указанного в `HS_PARENT_PID`.
- [x] `npm run tasks:check` и проверки CI зелёные, включая SEA-сборку и smoke на Windows, Linux и macOS:
  run 45935906242 на `9be192e` (ветка, обновлённая от `main` 498313b). «Performance budgets» с первой
  попытки упал на нестабильном замере генерации (515 мс при бюджете 500 мс; INT-005 генератор не
  меняет, в `main` этот замер тоже нестабилен) и прошёл после перезапуска. Последующие изменения —
  только статус задачи.
