# INT-005 — Упаковка сервера в исполняемый файл (Node SEA) и запуск из Godot

## Описание

В релизе игрок не должен устанавливать Node.js (ADR 0002, риск R-03).

## Цель

Godot-игра запускает встроенный сервер и подключается к нему.

## Scope

- Сборка сервера (бандл + Node.js Single Executable Application) для Windows, Linux, macOS.
- ServerLauncher: запуск дочернего процесса, ожидание /health, завершение при выходе.
- Свободный порт при занятости 7420.
- Подпись/нотаризация — отдельный вопрос (OQ-09).

## Out of Scope

- Экспорт Godot (REL-001).

## Зависимости

- [SRV-008](SRV-008.md) — Сетевая конфигурация: LAN-адреса для QR привязки, привязка к интерфейсам
- [GDT-001](GDT-001.md) — Autoload Backend: REST и WebSocketPeer, переподключение

## Затрагиваемые модули

- `apps/server/build`
- `apps/desktop/src/autoload/server_launcher.gd`

## Ожидаемый результат

Встроенный сервер.

## Критерии приёмки

- [ ] Godot-сборка на чистой Windows-машине без Node.js проходит привязку телефона.
- [ ] Процесс сервера завершается вместе с игрой.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Ручной + CI-сборка артефакта.

## Требования к документации

- ADR — при отклонении от Node SEA; docs/development/setup.md.
