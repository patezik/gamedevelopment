# INT-001 — Интеграция привязки: Godot ↔ сервер ↔ телефон

## Описание

Проверка привязки и синхронизации для M5 выполняется на штатной сборке сервера из SRV-013 (M6).

## Цель

Подтверждено, что три компонента работают вместе.

- Автотест: FakeDesktop + FakePhone проходят привязку и обмен view.update.
