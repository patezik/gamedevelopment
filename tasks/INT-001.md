# INT-001 — Интеграция привязки: Godot ↔ сервер ↔ телефон

## Описание

Проверка привязки и синхронизации для M5 выполняется на штатной сборке сервера из SRV-013 (M6).

## Цель

Подтверждено, что три компонента работают вместе.

## Scope

- Автотест: FakeDesktop + FakePhone проходят привязку и обмен view.update.
- Ручной чек-лист: реальный Godot + физический iPhone, разрыв Wi-Fi и восстановление.
- Чек-лист сохраняется в docs/testing/pairing-checklist.md.

## Out of Scope

- Игровой процесс.

- [TOOL-001](TOOL-001.md) — Фейковые клиенты desktop/phone (CLI и библиотека) для тестов
