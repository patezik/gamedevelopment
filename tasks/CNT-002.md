# CNT-002 — MVP-сценарий: локации, предметы, архетипы, отношения (данные)

## Описание

Данные пресета «Санаторий „Сосновый бор“» (docs/game-design/mvp-scenario-sanatorium.md).

Изменение Scope (решение владельца, 21.11.2026): загрузчик `loadScenarioFromDir` требует все девять
корневых файлов, а `crossCheck` — существующие шаблоны инцидентов и правила следов для их глаголов.
Без этих данных критерий «content:check зелёный» недостижим, поэтому CNT-002 включает минимальный
согласованный каркас `motives.json`, `crimes.json`, `trace-rules.json` и `deduction-rules.json`.
Каркас не заменяет CNT-003/CNT-004. Сеттинг — рабочее решение по OQ-12: январь 2026, приглушённая
аналоговая хоррор-эстетика.

## Цель

Мир MVP-сценария доступен генератору.

## Scope

- preset.json, locations.json (12 локаций), items.json, archetypes.json (≥ 8 архетипов на 7 мест), relationships.json (шаблоны + секреты ≥ 15 видов).
- Пулы имён (русские, эпоха пресета).
- Фрагменты биографий ≥ 60 с тегами.
- Распорядки NPC в архетипах; физические ключи и начальные размещения предметов.
- Временный каркас для загрузчика: минимальные согласованные `motives.json`, `crimes.json`,
  `trace-rules.json`, `deduction-rules.json`.

## Out of Scope

- Полные преступления и мотивы (CNT-003), полные правила следов и дедукции (CNT-004), тексты
  (CNT-005), контент телефона (CNT-006).
- Изменения схем, `crossCheck`, загрузчика и CI.

## Зависимости

- [x] content:check зелёный.

- [x] Каждая локация имеет описание и ≥ 2 точки интереса.
- [x] 12 связанных локаций, ≥ 8 архетипов, ≥ 60 фрагментов биографий, ≥ 15 видов секретов
  (локальная проверка, результат в PR).
- [x] `npm run tasks:check` и проверки CI зелёные.
