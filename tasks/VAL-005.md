# VAL-005 — Проверки V-REDUNDANCY и V-CLEANUP

## Описание

Пропуск события или сокрытие улики не должны делать игру нерешаемой (validation.md §1).

## Цель

Расследования устойчивы к поведению NPC и выбору игрока.

## Scope

- Минимальный разрез: ≥ 2 независимых пути для мотива, средства, возможности.
- Пассивная симуляция сокрытия без игрока до t_safe (25 % длительности).

## Out of Scope

- —

- [SIM-005](SIM-005.md) — Цели ConcealEvidence, SpreadRumor, ProtectSelf, MeetCharacter, SeekInformation

Две проверки.

## Критерии приёмки

- [ ] Мутация «единственная улика средства» ловится V-REDUNDANCY.
- [ ] V-CLEANUP находит момент потери решаемости.
- [ ] `npm run tasks:check` и проверки CI зелёные.
