# EVD-003 — Режим фиксации улик телефоном и порт EvidenceTokenPort

## Описание

Часть улик фиксируется только камерой телефона (qr-mechanics.md §2).

## Цель

Ядро умеет запросить токен улики, не зная о сервере.

## Scope

- captureMode "qr" | "auto"; распределение по правилам (доля minQrShare пресета).
- Интерфейс EvidenceTokenPort { issue, revoke }; фейковая реализация для тестов.
- Состояние pendingCapture в движке (связано с ENG-004).

## Out of Scope

- Серверная реализация токенов (SRV-006).

## Зависимости

- [EVD-002](EVD-002.md) — Улики (Clue): поддерживаемые утверждения, условия обнаружения, точки интереса

## Затрагиваемые модули

- `packages/core/src/evidence/capture.ts`

## Ожидаемый результат

Порт и логика режима фиксации.

## Критерии приёмки

- [ ] Доля qr-улик среди обязательных ≥ minQrShare (проверяется VAL-006).
- [ ] Фейковый порт детерминирован.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Unit.
