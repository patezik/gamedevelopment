# FND-010 — Оркестрация разработки и проверка setup.md на чистой машине

## Описание

Новый участник должен поднять всё окружение по одному документу.

## Цель

От git clone до работающих сервера, Godot-клиента и Expo-приложения — по инструкции без догадок.

## Scope

- Корневые скрипты dev:server, dev:mobile, test:all.
- .env.example для сервера.
- Пройти docs/development/setup.md с нуля (новый клон), исправить все неточности.
- Раздел «Частые проблемы» (порт занят, брандмауэр Windows, телефон в другой сети, вход в Expo Go).

## Out of Scope

- Запуск сервера из Godot (INT-005).

## Зависимости

- [FND-005](FND-005.md) — Каркас apps/server: Fastify 5, конфигурация, /health, логирование
- [FND-006](FND-006.md) — Bootstrap apps/mobile: Expo SDK 58, Expo Router, TypeScript, jest-expo
- [FND-008](FND-008.md) — GUT 9.7.x, headless-запуск тестов Godot и CI-job

## Затрагиваемые модули

- `package.json`
- `docs/development/setup.md`
- `.env.example`

## Ожидаемый результат

setup.md проверен и исправлен; в PR приложен лог прохождения инструкции.

## Критерии приёмки

- [ ] Все команды из setup.md выполняются как написано.
- [ ] Разделы для Windows, macOS, Linux.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Ручная проверка на чистом клоне.

## Требования к документации

- docs/development/setup.md.
