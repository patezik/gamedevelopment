# GEN-005 — Стадия ConflictGen: правила мотивов для всех пар персонажей

## Описание

Мотивы вычисляются для всех упорядоченных пар, а не назначаются ролям.

## Цель

Полная матрица потенциальных конфликтов мира.

## Scope

- Интерпретатор правил motives.json (условия на отношения, секреты, черты).
- MotiveCandidate { who, against, motiveType, strength, basis: FactId[] }.
- Факты motive в истине для кандидатов выше порога.

## Out of Scope

- Выбор жертвы и виновника (GEN-006).

## Зависимости

- [GEN-004](GEN-004.md) — Стадия SocialGen: отношения и секреты

## Затрагиваемые модули

- `packages/generator/src/stages/conflict-gen.ts`

## Ожидаемый результат

Стадия ConflictGen.

## Критерии приёмки

- [ ] Каждый кандидат ссылается на базовые факты.
- [ ] Отчёт: распределение силы мотивов.
- [ ] Тест на ручной фикстуре: ожидаемые мотивы найдены.
- [ ] `npm run tasks:check` и проверки CI зелёные.
