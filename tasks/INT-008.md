# INT-008 — Спайк: TLS с pinning через QR и облачный ретранслятор → ADR

## Описание

MVP использует HTTP в LAN (ADR 0008). Нужно решение для повышения безопасности и для сетей без прямой видимости.

## Цель

Обоснованное решение с прототипом.

## Scope

- Прототип самоподписанного сертификата с отпечатком в QR привязки.
- Оценка облачного ретранслятора (стоимость, приватность, задержки).
- ADR с рекомендацией.

## Out of Scope

- Внедрение в продукт.

## Зависимости

ADR и прототип.
