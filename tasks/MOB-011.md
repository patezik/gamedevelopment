# MOB-011 — Психологические эффекты ОС телефона: глитчи, искажения, обои

## Описание

Телефон «сбоит» при росте помех (survival-horror.md §5).

## Цель

Телефон становится источником тревоги.

## Scope

- effects.glitchLevel → дрожание, шум, подмена текста, искажение превью (reanimated).
- Уважение настройки «Снизить эффекты».

## Out of Scope

- —

## Зависимости

- [MOB-005](MOB-005.md) — Уведомления и входящие события в ОС (тосты, бейджи, вибрация, звук)
- [SURV-005](SURV-005.md) — Галлюцинации на телефоне и проверка V-HALLUCINATION

## Затрагиваемые модули

- `apps/mobile/src/os/effects`

## Ожидаемый результат

Эффекты ОС.

## Критерии приёмки

- [x] Эффекты не мешают сканированию QR (камера без эффектов). Проверено RNTL при уровне 100.
- [x] Ручная проверка исходной реализации на физическом iPhone через Expo Go. Автор PR подтвердил 26.11.2026 прохождение всех шести этапов без замечаний.
- [x] Повторная ручная проверка после интеграции Gallery с MOB-008. Автор PR подтвердил на физическом iPhone через Expo Go для `72a3f73`: VoiceOver, миниатюры и подписи, метаданные, масштабирование и возврат в сетку, оба режима снижения эффектов и QR при уровне 100. Замечаний нет.
- [x] `npm run tasks:check` и все применимые проверки CI на `72a3f73` прошли. Performance budgets прошёл со второй попытки. [Прогон CI](https://github.com/patezik/gamedevelopment/actions/runs/45858560220/attempts/2).

## Требования к тестированию

- RNTL (наличие и отключение эффектов, доступные имена, открытие, масштабирование и закрытие снимка при уровне 100).
- Стенд Expo Go для всех уровней, обоев и тестового QR описан в
  [mobile-app.md](../docs/mobile/mobile-app.md#ручная-проверка-эффектов-на-iphone-mob-011).
