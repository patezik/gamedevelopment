# MOB-011 — Психологические эффекты ОС телефона: глитчи, искажения, обои

## Описание

Телефон «сбоит» при росте помех (survival-horror.md §5).

## Цель

Телефон становится источником тревоги.

## Scope

- effects.glitchLevel → дрожание, шум, подмена текста, искажение превью (reanimated).
- Уважение настройки «Снизить эффекты».

## Out of Scope

- —

## Зависимости

- [MOB-005](MOB-005.md) — Уведомления и входящие события в ОС (тосты, бейджи, вибрация, звук)
- [SURV-005](SURV-005.md) — Галлюцинации на телефоне и проверка V-HALLUCINATION

## Затрагиваемые модули

- `apps/mobile/src/os/effects`

## Ожидаемый результат

Эффекты ОС.

## Критерии приёмки

- [x] Эффекты не мешают сканированию QR (камера без эффектов). Проверено RNTL при уровне 100.
- [x] Ручная проверка на физическом iPhone через Expo Go. Владелец подтвердил 26.11.2026, что прошли все шесть этапов: привязка, уровни помех, обои, «Снизить эффекты», системное уменьшение движения и сканирование QR при уровне 100. Замечаний нет.
- [ ] `npm run tasks:check` и проверки CI зелёные. Локальная проверка карточки проходит. В последнем прогоне GitHub CI упал бенчмарк симуляции. [Прогон CI](https://github.com/patezik/gamedevelopment/actions/runs/45851595280).

## Требования к тестированию

- RNTL (наличие/отключение эффектов).
