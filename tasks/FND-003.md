# FND-003 — CI: Node-задачи (lint, typecheck, test, coverage) с фильтрами путей

## Описание

Сейчас CI проверяет только задачи и ссылки документации. Нужно добавить проверки TypeScript-кода.

## Цель

Каждый PR автоматически проверяется линтером, типами и тестами.

## Scope

- Job node: setup-node с версией из .nvmrc, npm ci, lint, typecheck, test --coverage.
- Кэш npm.
- Пороги покрытия: core 85 %, generator/validator 80 % (включаются, когда пакеты появятся).
- Закрепить мажорные версии actions.

## Out of Scope

- Godot CI (FND-008).
- Seed sweep (VAL-008).
- Сборка мобильного приложения.

## Зависимости

- [FND-001](FND-001.md) — Корневой TypeScript-тулчейн: TS 6, ESLint 10, Prettier, Vitest 5

## Затрагиваемые модули

- `.github/workflows/ci.yml`

## Ожидаемый результат

PR с ошибкой типов или упавшим тестом получает красный статус.

## Критерии приёмки

- [x] Workflow запускается на push в main и на pull_request.
- [x] Время job ≤ 5 минут на текущем объёме.
- [x] Существующие job tasks/docs не сломаны.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Проверить на тестовой ветке, что намеренная ошибка типов роняет CI.

## Требования к документации

- docs/development/git-workflow.md — список обязательных проверок PR.
