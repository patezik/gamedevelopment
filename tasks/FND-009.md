# FND-009 — Каркасы пакетов @hs/core, @hs/generator, @hs/validator

## Описание

Ядро, генератор и валидатор — отдельные пакеты с явными зависимостями (ADR 0001).

## Цель

Агенты фазы 2+ работают в готовых пакетах, не настраивая сборку.

## Scope

- Три пакета с package.json, tsconfig (extends base), src/index.ts, smoke-тестом.
- Зависимости: generator → core, validator → core; generator → validator (шлюз); validator не зависит от generator.
- Структура каталогов @hs/core по docs/architecture/modules.md (только index.ts в модулях, которые реально создаются задачами — пустые каталоги не создавать).
- @hs/core зависит только от zod.

## Out of Scope

- Любая игровая логика.

## Зависимости

- [FND-001](FND-001.md) — Корневой TypeScript-тулчейн: TS 6, ESLint 10, Prettier, Vitest 5

## Затрагиваемые модули

- `packages/core`
- `packages/generator`
- `packages/validator`

## Ожидаемый результат

Пакеты собираются, тесты проходят, граф зависимостей соответствует ADR.

## Критерии приёмки

- [x] npm run typecheck и npm test зелёные.
- [x] Импорт @hs/core из @hs/generator работает через workspace.
- [x] Нет циклических зависимостей пакетов.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Smoke-тест в каждом пакете.

## Требования к документации

- docs/architecture/modules.md — если уточнены пути.
