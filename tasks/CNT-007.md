# CNT-007 — Тюнинг MVP-пресета до порогов seed sweep

## Описание

Веха M4 требует, чтобы MVP-пресет проходил пороги качества.

## Цель

Неудачи < 1 %, энтропия виновников ≥ 0,8 от максимума, каждый архетип — виновник ≥ 5 %.

## Scope

- Запуск sweep, анализ отчёта, правка данных (не кода ядра).
- Если нужны изменения кода — отдельные задачи с описанием.
- Итоговый отчёт sweep в docs/planning/reports/ (Markdown).

## Out of Scope

- Изменения алгоритмов генератора.
