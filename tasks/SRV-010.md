# SRV-010 — Проводка texts, проекций и событий в Session Server

## Описание

SRV-005 принимает проекции через опции шлюза `snapshot` и `events`, но реальные `GameEngine.playerView`, `projectPhoneView` и отображение доменных событий в `ClientEvent` не подключены; движок сессии не получает `texts` (ENG-009), поэтому клиенты видят ключи шаблонов вместо текста.

## Цель

Клиенты получают настоящие представления и русские реплики от сервера.

## Scope

- Подключить проекции движка к рассылке `view.update` по ролям.
- Отобразить доменные события в `ClientEvent` с фильтром видимости.
- Передавать `texts` сценария в `EnginePorts` через общий провайдер из SRV-012, используемый при создании и регенерации сессии.

## Out of Scope

- Создание сессий (SRV-002) и связывание менеджера, шлюза и QR в штатном процессе ([SRV-013](SRV-013.md)).
- Клиентские экраны.

## Зависимости

- [ENG-009](ENG-009.md) — Проекция реплик NPC

## Ожидаемый результат

Две роли получают корректные представления и текст, события доходят только до тех, кому видны.

## Критерии приёмки

- [x] `view.update` содержит настоящие `PlayerView` и `PhoneView` по ролям.
- [x] События фильтруются по роли, утечек истины нет (тест на реальной проекции).
- [x] Реплики приходят текстом, а не ключами.
- [x] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию
