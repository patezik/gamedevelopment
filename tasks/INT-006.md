# INT-006 — Мастер сетевого подключения в Godot (брандмауэр, выбор сети, диагностика)

## Описание

LAN-проблемы — главный риск привязки (R-04).

## Цель

Игрок сам решает типичные сетевые проблемы.

## Scope

- Диагностика: доступность порта, список адресов, подсказки по брандмауэру и гостевым сетям.
- Проверка «телефон видит компьютер» через тестовый запрос с телефона.

## Out of Scope

- Облачный ретранслятор.

## Зависимости

- [INT-005](INT-005.md) — Упаковка сервера в исполняемый файл (Node SEA) и запуск из Godot
- [SRV-008](SRV-008.md) — Сетевая конфигурация: LAN-адреса для QR привязки, привязка к интерфейсам

## Затрагиваемые модули

- `apps/desktop/src/scenes/pairing`

## Ожидаемый результат

Мастер подключения.
