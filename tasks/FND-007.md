# FND-007 — Каркас Godot-проекта apps/desktop (Godot 4.7.2, строгий GDScript)

## Описание

Desktop-клиент на Godot (ADR 0011). Нужен проект с согласованной структурой каталогов и строгой типизацией.

## Цель

Проект открывается в Godot 4.7.2 и запускается headless без ошибок.

## Scope

- project.godot: имя, config/features 4.7, главная сцена-заглушка, окно 1920×1080 с масштабированием canvas_items.
- Предупреждения untyped_declaration, unsafe_property_access, unsafe_method_access, unsafe_call_argument → error.
- Каталоги src/autoload, src/net, src/scenes, src/ui, assets, tests (с .gdignore там, где не нужен импорт).
- .gitignore для .godot/ и экспортов.
- Главная сцена показывает версию клиента.

## Out of Scope

- GUT (FND-008).
- Сетевые autoload (GDT-001).

## Зависимости

- Нет — задачу можно начинать сразу.

## Затрагиваемые модули

- `apps/desktop`

## Ожидаемый результат

godot --headless --path apps/desktop --quit завершается с кодом 0.

## Критерии приёмки

- [ ] Godot 4.7.2 открывает проект без миграций.
- [ ] Скрипт без типов в src/ вызывает ошибку анализатора (проверено вручную и описано в PR).
- [ ] Структура каталогов соответствует docs/desktop/godot-client.md.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Ручной запуск headless (автоматизация — FND-008).

## Требования к документации

- docs/desktop/godot-client.md — если структура уточнена.
