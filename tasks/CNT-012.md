# CNT-012 — Полный набор арта sanatorium_winter: пластины локаций и портреты

## Описание

CNT-010 дал стайлгайд, пайплайн и эталоны (3 локации, 2 портрета). Для MVP нужен полный
набор: 12 локаций в каждом используемом уровне освещения (29 пластин) и портреты всех 9
архетипов. Источник финального арта и допустимые лицензии решает владелец (OQ-08) — **начинать
только после этого решения**.

## Цель

Все локации и архетипы `sanatorium_winter` имеют арт, проходящий `npm run art:check`, с
записанным происхождением.

## Scope

- 29 пластин 384×216 по [art-direction.md](../docs/game-design/art-direction.md) §5, §7.
- Портреты 96×128: по одному варианту на каждый пол, встречающийся в пуле имён архетипа.
- Замена или подтверждение эталонов CNT-010; записи `provenance.json` со статусом `final`
  только для ассетов с решённой лицензией.

## Out of Scope

- Показ в клиенте (GDT-012), заполнение `portraitRef` (ENG-008), звук (CNT-011).

## Зависимости

- [CNT-010](CNT-010.md) — Арт-направление и пайплайн ассетов локаций и портретов

## Затрагиваемые модули

- `apps/desktop/assets/art/scenarios/sanatorium_winter`

## Ожидаемый результат

Полный набор арта MVP-сценария.

## Критерии приёмки

- [ ] У каждой локации есть пластины всех её уровней освещения; у каждого архетипа — портреты.
- [ ] `npm run art:check` и `npm run test:godot` зелёные.
- [ ] Происхождение и лицензия каждого файла соответствуют решению по OQ-08.

## Требования к тестированию

- `npm run art:check`; визуальная проверка в `tests/manual/art_preview.tscn`.

## Требования к документации
