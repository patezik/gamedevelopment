# MOB-006 — Приложения Contacts и Calls: звонки с выбором реплик

## Описание

Связь с персонажами через телефон (mobile-app.md §4).

## Цель

Игрок звонит персонажам и принимает звонки.

## Scope

- Список контактов, карточка контакта (звонок/сообщение).
- Экран активного звонка: реплики NPC, варианты игрока (callChoice), завершение.
- Журнал звонков, пропущенные.
- Неизвестные номера.

## Out of Scope

- —

## Зависимости

- [MOB-005](MOB-005.md) — Уведомления и входящие события в ОС (тосты, бейджи, вибрация, звук)
- [ENG-004](ENG-004.md) — Действия телефона: звонки, сообщения, браузер, файлы, заметки, фиксация улик

## Затрагиваемые модули

- `apps/mobile/src/os-apps/contacts`
- `apps/mobile/src/os-apps/calls`

## Ожидаемый результат

Два приложения.

## Критерии приёмки

- [x] RNTL на фикстурах; ручная проверка входящего звонка. Проверено на iPhone в демо-режиме: экран звонка, реплики, варианты ответа, сообщение «Нет связи» без сервера. Журнал, «Позвонить» и «Неизвестный номер» в демо не воспроизводятся (активный звонок не завершается без сервера): покрыто тестами RNTL, сквозная проверка с сервером входит в INT-001.
- [x] `npm run tasks:check` и проверки CI зелёные.
