# FND-008 — GUT 9.7.x, headless-запуск тестов Godot и CI-job

## Описание

Нужны автотесты GDScript (ADR 0011).

## Цель

GUT-тесты запускаются локально и в CI одной командой.

## Scope

- Вендорить GUT 9.7.x (последний патч, совместимый с 4.7) в apps/desktop/addons/gut; записать версию и лицензию.
- .gutconfig.json: каталоги tests/unit и tests/contract.
- Скрипт npm run test:godot (вызывает Godot из переменной GODOT_BIN).
- Пример теста tests/unit/test_smoke.gd.
- CI job godot: скачать Godot 4.7.2 Linux headless с GitHub Releases, кэшировать, запустить тесты; фильтр путей apps/desktop/** и packages/protocol/**.

## Out of Scope

- Контрактные тесты протокола (PROTO-003).

## Зависимости

- [FND-007](FND-007.md) — Каркас Godot-проекта apps/desktop (Godot 4.7.2, строгий GDScript)
- [FND-003](FND-003.md) — CI: Node-задачи (lint, typecheck, test, coverage) с фильтрами путей

## Затрагиваемые модули

- `apps/desktop/addons/gut`
- `.github/workflows/ci.yml`

## Ожидаемый результат

npm run test:godot и CI-job проходят на примере теста.

## Критерии приёмки

- [ ] Упавший GUT-тест даёт ненулевой код возврата и красный CI.
- [ ] Версия GUT указана в tech-stack.md.
- [ ] Время job ≤ 4 минут с кэшем.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- test_smoke.gd: базовая проверка (например, что ProjectSettings содержит имя проекта).

## Требования к документации

- docs/development/setup.md — как установить Godot и задать GODOT_BIN.
