# MOB-003 — WebSocket-клиент и сторы Zustand: hello/resume, backoff, offline

## Описание

Синхронизация телефона с сессией (mobile-app.md §5).

## Цель

Телефон переживает блокировку экрана, смену сети и перезапуск сервера.

## Scope

- WsClient: hello с resume, ping 10 с, экспоненциальная задержка с джиттером.
- connectionStore, phoneStore (stateVersion по возрастанию).
- Валидация входящих zod-схемами.
- DEVICE_REVOKED → удаление токена, переход на /pair.
- Обработка AppState (фон/активен).

## Out of Scope

- UI приложений.

## Зависимости

- [MOB-002](MOB-002.md) — Экран привязки: скан QR привязки, ручной ввод, SecureStore
- [PROTO-002](PROTO-002.md) — Схемы PlayerView и PhoneView с фикстурами

## Затрагиваемые модули

- `apps/mobile/src/connection`
- `apps/mobile/src/stores`

## Ожидаемый результат

Клиент и сторы.

## Критерии приёмки

- [ ] Тесты с mock WebSocket: resume, backoff, невалидные сообщения, revoked.
- [ ] Баннер «Нет связи с игрой» при offline.
- [ ] `npm run tasks:check` и проверки CI зелёные.
