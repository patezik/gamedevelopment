# INT-002 — E2E-бот: прохождение расследования через реальный сервер по SolutionPath

## Описание

Сквозная проверка всей серверной цепочки (testing-strategy.md §1).

## Цель

Доказано, что расследование проходится от привязки до концовки через протокол.

## Scope

- Бот: FakeDesktop + FakePhone, привязка, исполнение SolutionPath (действия phone — через FakePhone, QR — через scanQr по pendingCapture), обвинение.
- Хаос-режим: случайные разрывы; итоговый stateHash совпадает с прогоном без разрывов.
- CI: 10 seed на PR, 200 nightly.

## Out of Scope

- Godot и реальный телефон.

## Зависимости

- [VAL-003](VAL-003.md) — Планировщик по времени: V-TIME-FEASIBLE и SolutionPath
- [SRV-005](SRV-005.md) — Рассылка представлений и событий с фильтром по роли
- [TOOL-001](TOOL-001.md) — Фейковые клиенты desktop/phone (CLI и библиотека) для тестов
- [ENG-004](ENG-004.md) — Действия телефона: звонки, сообщения, браузер, файлы, заметки, фиксация улик
- [ENG-006](ENG-006.md) — Действие accuse, концовки и TruthRecap

## Затрагиваемые модули

E2E-бот.
