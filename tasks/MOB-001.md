# MOB-001 — Оболочка виртуальной ОС: домашний экран, реестр приложений, статус-бар

## Описание

Мобильное приложение имитирует ОС с независимыми приложениями (mobile-app.md §3).

## Цель

Новое приложение добавляется одной папкой и строкой в реестре.

## Scope

- OsAppManifest, registry.ts, маршрут /os/[appId].
- HomeGrid с бейджами, AppFrame с кнопкой «домой», StatusBar (игровое время, заряд, «сигнал»).
- Работа на фикстурах PhoneView (до подключения сервера).
- Приложения-заглушки для 10 приложений MVP (заглушка = заголовок «в разработке», не пустой файл).

## Out of Scope

- Реальные приложения (MOB-004, MOB-006…010).

## Зависимости

- [FND-006](FND-006.md) — Bootstrap apps/mobile: Expo SDK 58, Expo Router, TypeScript, jest-expo
- [PROTO-002](PROTO-002.md) — Схемы PlayerView и PhoneView с фикстурами

## Затрагиваемые модули

- `apps/mobile/src/os`
- `apps/mobile/src/os-apps/registry.ts`
- `apps/mobile/app/os`

## Ожидаемый результат

Оболочка ОС.
