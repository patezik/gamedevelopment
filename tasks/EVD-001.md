# EVD-001 — Движок правил следов: TraceRule → Trace, закон сохранения улик

## Описание

Каждое действие оставляет следы по данным правил (modules.md §8).

Состояние: реализованы интерпретатор `TraceRule → Trace` (`compileTraceRules`, `tracesForEvent`,
`deriveTraces`), закон сохранения улик, полезная нагрузка следа (`template`, `supports`,
`captureMode`, `itemId`), `requires`, уничтожение (`destroyedBy`/`destroyedAt`) и
`isTraceAvailable`. Решения OQ-14…OQ-17 — [ADR 0017](../docs/architecture/adr/0017-trace-conservation-and-payload.md).

Критерий tiny-manor проверен временной интеграцией с [CORE-003](CORE-003.md) (PR #32, `db227f9`),
[TRUTH-003](TRUTH-003.md) (PR #33, `2b12b6b`) и [CNT-002](CNT-002.md) (PR #37, `6bd82bc`):
фикстура `tinyManor` в `main` отсутствует и не входит в `depends_on`, поэтому постоянный тест
добавляется после merge CORE-003 (код CORE-003 в эту задачу не копируется). Property-тесты по
журналам генератора переносятся на GEN-008.

`traceRulesSchema` (контент) и `compileTraceRules` используют общие `verbSchema` и
`TRACE_LOCATION_PLACEHOLDERS`, поэтому список `modules` включает `content/schemas.ts` и
`common/verb.ts`. Прямой импорт через Node type stripping работает для `evidence/traces.ts`, но
не для модулей `truth` (`TruthError` использует parameter properties) — существующее ограничение
вне Scope.

## Цель

Улики выводятся из событий истины, а не придумываются.

## Scope

- Интерпретатор trace-rules.json: условие, kind, место, окно доступности, decay.
- Trace с sourceEventId.
- Закон сохранения: события hide/destroy/stage обязаны порождать вторичный след — иначе ошибка загрузки правил.

## Out of Scope

- Улики и обнаружение (EVD-002).
