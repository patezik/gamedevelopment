# SRV-002 — REST: создание сессии и список сценариев

## Описание

Desktop создаёт сессию по сценарию и seed.

## Цель

Godot может начать новую игру через API.

## Scope

- GET /api/v1/scenarios, POST /api/v1/sessions (seed опционален — генерируется серверным CSPRNG в виде читаемой строки).
- desktopToken (хранится хеш).
- Ошибки SCENARIO_NOT_FOUND, GENERATION_UNSOLVABLE.

## Out of Scope

- Привязка (SRV-003).

## Зависимости

- [SRV-001](SRV-001.md) — SessionManager: сессии, очередь действий, жизненный цикл
- [GEN-011](GEN-011.md) — generateInvestigation: шлюз валидации, ремонт, CLI hs-gen

## Затрагиваемые модули

- `apps/server/src/routes/sessions.ts`

## Ожидаемый результат

Эндпоинты сессий.
