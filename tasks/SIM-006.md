# SIM-006 — Реакции NPC на игрока: настороженность, AvoidPlayer, реакции на обвинение

## Описание

Мир реагирует на действия игрока (character-simulation.md §5).

## Цель

Игрок чувствует, что персонажи помнят его вопросы и действия.

## Scope

- PlayerActionObserved → wariness по чувствительности тем.
- Цель AvoidPlayer.
- Реакции на ложное/верное обвинение (investigation-model.md §6).
- Реакции на смерть/исчезновение персонажей.

## Out of Scope

- Нападения (SURV-003).

## Зависимости

- [SIM-005](SIM-005.md) — Цели ConcealEvidence, SpreadRumor, ProtectSelf, MeetCharacter, SeekInformation
- [ENG-003](ENG-003.md) — Действия desktop: осмотр, разговор, допрос, чтение, предметы, замки, отдых

## Затрагиваемые модули

- `packages/core/src/simulation/reactions.ts`

## Ожидаемый результат

Реакции NPC.

## Критерии приёмки

- [ ] Вопрос по теме повышает wariness только у затронутых (тест).
- [ ] После ложного обвинения обвиняемый отказывается говорить.
- [ ] `npm run tasks:check` и проверки CI зелёные.

- Unit + сценарные тесты.
