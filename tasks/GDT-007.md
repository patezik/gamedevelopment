# GDT-007 — Оверлей фиксации улики: показ QR, ожидание скана, результат

## Описание

Связка desktop → телефон для улик (overview.md §4).

## Цель

Игрок понимает, что улику нужно «сфотографировать» телефоном.

## Scope

- При pendingCapture — запрос матрицы, показ QR с подписью, таймер срока (игровые минуты).
- Закрытие по view.update (улика в деле) или отмена.
- Подсказка, если телефон offline.
