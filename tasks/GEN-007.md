# GEN-007 — Стадия PlotPlanning: план виновника, окно возможности, изгиб расписания

## Описание

Преступление встраивается в расписания мира правдоподобно.

## Цель

План виновника выполним в мире и даёт причинно-следственную цепочку.

## Scope

- Шаги шаблона (acquire, act, conceal…) → цели ExecutePlot с временными окнами.
- ScheduleOverride для окна возможности (не более 1 блока; причина записывается фактом).
- Планируемая ложь-алиби (что виновник будет утверждать).
- Окно инцидента в IncidentRecord.

## Out of Scope

- Исполнение плана (GEN-008).

## Зависимости

- [GEN-006](GEN-006.md) — Стадия IncidentSelection: жертва, шаблон, виновник из всех допустимых
- [TRUTH-002](TRUTH-002.md) — TruthLog, TruthModel и IncidentRecord

## Затрагиваемые модули

- `packages/generator/src/stages/plot-planning.ts`

## Ожидаемый результат

Стадия планирования.

- [ ] План проходит проверку выполнимости перемещений по графу.
- [ ] Изгиб расписания имеет объяснимую причину (факт).
- [ ] `npm run tasks:check` и проверки CI зелёные.
