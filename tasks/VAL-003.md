# VAL-003 — Планировщик по времени: V-TIME-FEASIBLE и SolutionPath

## Описание

Решение должно укладываться в отведённое время (validation.md §3).

## Цель

Каждое расследование имеет найденный машиной путь решения с запасом времени.

## Scope

- Beam search (ширина 8) по действиям с реальными стоимостями и расписаниями NPC (через GameEngine в режиме симуляции).
- SolutionPath — список PlayerAction.
- V-TIME-FEASIBLE: путь ≤ 70 % длительности.

## Out of Scope

- Учёт сокрытия улик (VAL-005).

## Зависимости

- [VAL-002](VAL-002.md) — Солвер решаемости: V-REACHABLE, V-CULPRIT-PROVABLE, V-UNIQUE
- [ENG-001](ENG-001.md) — GameEngine: агрегат состояния, dispatch, действия move и wait

## Затрагиваемые модули

- `packages/validator/src/planner`

## Ожидаемый результат

Планировщик.

## Критерии приёмки

- [ ] SolutionPath, воспроизведённый через GameEngine, приводит к установлению M/M/O виновника.
- [ ] Время работы ≤ 300 мс на расследование MVP.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Integration: план → движок → claims.
