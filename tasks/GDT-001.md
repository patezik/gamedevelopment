# GDT-001 — Autoload Backend: REST и WebSocketPeer, переподключение

## Описание

Сетевой слой Godot (godot-client.md §3).

## Цель

Сцены получают данные сервера через сигналы, не зная о сети.

## Scope

- REST через HTTPRequest (очередь, таймауты, Authorization).
- WebSocketPeer: poll в _process, hello/resume, ping, разбор конверта.
- reconnect_policy.gd (экспоненциальная задержка с джиттером).
- Сигналы message_received, connection_state_changed.
