# FND-001 — Корневой TypeScript-тулчейн: TS 6, ESLint 10, Prettier, Vitest 5

## Описание

В корне уже есть npm workspaces и скрипты задач. Нужно добавить общий TypeScript-тулчейн, на котором будут строиться все TS-пакеты.

## Цель

Любой новый пакет подключается к линтингу, проверке типов и тестам без собственной настройки.

## Scope

- Установить typescript 6.0.x, eslint 10.x, typescript-eslint 8.72.x, prettier 3.9.x, vitest 5.0.x, @types/node (dev, корень).
- Создать tsconfig.base.json (strict, noUncheckedIndexedAccess, exactOptionalPropertyTypes, module NodeNext, target ES2024).
- Создать eslint.config.mjs (flat config) с typescript-eslint recommendedTypeChecked и prettier-совместимостью.
- Создать .prettierrc.json и .prettierignore.
- Добавить корневые скрипты: lint, typecheck, test, format, format:check.
- Зафиксировать точные версии в package-lock.json.

## Out of Scope

- Создание пакетов packages/* и apps/* (FND-005, FND-006, FND-009).
- Правила детерминизма (FND-002).
- CI (FND-003).

## Зависимости

- Нет — задачу можно начинать сразу.

## Затрагиваемые модули

- `package.json`
- `tsconfig.base.json`
- `eslint.config.mjs`
- `vitest.workspace.ts`

## Ожидаемый результат

Команды npm run lint, npm run typecheck, npm run test выполняются в корне без ошибок (на пустом наборе пакетов — с понятным сообщением, не падают).

## Критерии приёмки

- [ ] Версии соответствуют docs/architecture/tech-stack.md.
- [ ] npm run lint, typecheck, test, format:check завершаются с кодом 0.
- [ ] package-lock.json закоммичен.
- [ ] Скрипты tasks:check и docs:check продолжают работать.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Временный тестовый файл в рамках PR показывает, что vitest находит *.test.ts в workspaces (удалить перед merge или оставить как smoke в FND-009).

## Требования к документации

- Обновить docs/development/setup.md (раздел «Команды») при изменении набора скриптов.
