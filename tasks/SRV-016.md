# SRV-016 — Seed незавершённой игры в списке сохранений

## Описание

`GET /api/v1/saves` без аутентификации возвращает `SaveSummary.seed` сразу после первого
сохранённого действия. Существующий тест SRV-007 проверяет именно такое поведение. В штатном
процессе маршрут появится вместе с [SRV-015](SRV-015.md). Для итогового разбора ENG-012 раскрывает
seed только в `PlayerView.ending`.

## Цель

Список сохранений даёт выбрать прохождение по метаданным и сохраняет seed незавершённого дела
на сервере.

## Scope

- Изменить только публичный ответ `GET /api/v1/saves`. Убрать seed из записей
  незавершённых игр, включая старые сохранения. Выдача seed для завершённых сохранений
  зависит от решения владельца по [OQ-40](../docs/planning/open-questions.md).
- Сохранить поля списка `saveId`, `scenarioId`, `updatedAt` и `gameTime`.
- Синхронизировать `SaveSummary` и `SaveList` из PROTO-006, фикстуру ответа и сгенерированную JSON Schema.
- Оставить seed в файле сохранения для загрузки и replay.

## Out of Scope

- Регистрация маршрута в штатном сервере (SRV-015) и атомарность
  `POST /api/v1/saves/:saveId/load` (SRV-014).
- Формат сохранения на диске, алгоритм загрузки и replay, диагностика, UI и `EndingView`.

## Зависимости

- [SRV-007](SRV-007.md) — существующие список и загрузка сохранений.

## Затрагиваемые модули

- `apps/server/src/saves/{routes,service,saves.test}.ts`
- `packages/protocol/src/rest.ts`, `fixtures/rest/saves.json`, `schemas/rest-save-list.json`
- `docs/backend/backend.md`

## Ожидаемый результат

К моменту подключения маршрута в SRV-015 публичный список скрывает seed незавершённых дел.

## Критерии приёмки

- [ ] После сохранения активной игры запись в `GET /api/v1/saves` сохраняет метаданные
  списка. Поле `seed` отсутствует.
- [ ] Старое незавершённое сохранение не раскрывает seed в списке и загружается с прежним хешем.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Fastify inject с настоящими `SaveService` и `SaveStore`. Проверить список после
  успешного действия и загрузку старого сохранения.
