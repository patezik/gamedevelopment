# ENG-004 — Действия телефона: звонки, сообщения, браузер, файлы, заметки, фиксация улик

## Описание

Телефон — устройство ввода игры (protocol.md §4).

## Цель

Часть расследования ведётся только с телефона.

## Scope

- call (диалог по телефону с ограниченным набором тем), answerCall, callChoice, message (шаблонные реплики, ответ NPC планируется симуляцией), browse, openFile, unlockFile(password), addNote, captureEvidence(tokenId).
- Расход заряда телефона.

## Out of Scope

- UI приложений.

## Зависимости

- [ENG-003](ENG-003.md) — Действия desktop: осмотр, разговор, допрос, чтение, предметы, замки, отдых
- [PHONE-001](PHONE-001.md) — Домен телефона: PhoneState, редьюсер событий, проекция PhoneView
- [EVD-003](EVD-003.md) — Режим фиксации улик телефоном и порт EvidenceTokenPort

## Затрагиваемые модули

- `packages/core/src/game/actions/phone`

## Ожидаемый результат

Действия телефона.

## Критерии приёмки

- [ ] Звонок неизвестному контакту невозможен.
- [ ] captureEvidence добавляет улику и снимает pendingCapture.
- [ ] Ответ на сообщение приходит через время, определяемое симуляцией.
- [ ] `npm run tasks:check` и проверки CI зелёные.
