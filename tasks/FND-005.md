# FND-005 — Каркас apps/server: Fastify 5, конфигурация, /health, логирование

## Описание

Session Server (ADR 0003) — точка синхронизации клиентов. Нужен минимальный работающий сервер.

## Цель

Сервер запускается командой и отвечает на /api/v1/health.

## Scope

- apps/server (@hs/server): fastify 5.12.x, tsx для dev.
- config/: чтение HS_PORT (7420), HS_HOST (0.0.0.0), HS_DATA_DIR, HS_LOG_LEVEL, HS_DEBUG_TRUTH с валидацией zod.
- GET /api/v1/health → { status, version, protocolVersion }.
- pino-логи, без токенов.
- Скрипты dev (tsx watch), start, test.
- Разделение app.ts (сборка) и server.ts (listen).

## Out of Scope

- Сессии, WebSocket, привязка (SRV-*).

## Зависимости

- [FND-001](FND-001.md) — Корневой TypeScript-тулчейн: TS 6, ESLint 10, Prettier, Vitest 5
- [FND-004](FND-004.md) — Пакет @hs/protocol: конверт, ErrorCode, версия, экспорт JSON Schema

## Затрагиваемые модули

- `apps/server`

## Ожидаемый результат

npm run dev -w @hs/server поднимает сервер на 7420; тесты через inject проходят.

## Критерии приёмки

- [ ] /api/v1/health возвращает protocolVersion из @hs/protocol.
- [ ] Неверная конфигурация (порт не число) — понятная ошибка при старте.
- [ ] Тест через fastify.inject без открытия порта.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Unit: парсинг конфигурации.
- Integration: inject GET /health.
