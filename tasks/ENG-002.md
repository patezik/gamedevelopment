# ENG-002 — Проекция PlayerView и тест отсутствия утечек истины

## Описание

Клиенты получают только знания игрока (overview.md §2, принцип 2).

## Цель

Истина гарантированно не попадает в desktop-клиент.

## Scope

- projectPlayerView(state) по схеме PlayerView из @hs/protocol.
- availableActions с costPreview.
- Тест утечек: сериализованный view не содержит ключей veracity, culpritIds, truth, hallucination и id персонажей, не встреченных игроком.

## Out of Scope

- PhoneView (PHONE-001).
- Доска дела наполняется в INV-*.

## Зависимости

- [ENG-001](ENG-001.md) — GameEngine: агрегат состояния, dispatch, действия move и wait
- [PROTO-002](PROTO-002.md) — Схемы PlayerView и PhoneView с фикстурами

## Затрагиваемые модули

- `packages/core/src/game/views.ts`

## Ожидаемый результат

PlayerView, проходящий схему протокола.

## Критерии приёмки

- [ ] Результат проходит zod-валидацию PlayerView.
- [ ] Тест утечек выполняется на 100 сгенерированных состояниях (после GEN-011 — на сгенерированных расследованиях; до — на tiny-manor).
- [ ] `npm run tasks:check` и проверки CI зелёные.
