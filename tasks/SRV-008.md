# SRV-008 — Сетевая конфигурация: LAN-адреса для QR привязки, привязка к интерфейсам

## Описание

Телефону нужен доступный адрес компьютера в LAN (риск R-04).

## Цель

QR привязки содержит адрес, по которому телефон реально достучится.

## Scope

- Список IPv4-адресов неинтерфейсов loopback/виртуальных (эвристика исключения VPN/WSL/Docker с возможностью выбора).
- GET /api/v1/network → кандидаты для Godot.
- Переменная HS_PUBLIC_HOST для ручного переопределения.
- Документ по брандмауэру Windows/macOS.

## Out of Scope

- UI-мастер подключения (INT-006).

## Зависимости

- [FND-005](FND-005.md) — Каркас apps/server: Fastify 5, конфигурация, /health, логирование

## Затрагиваемые модули

- `apps/server/src/config/network.ts`

## Ожидаемый результат

Определение адресов.
