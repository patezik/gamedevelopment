# GEN-008 — Стадия HistorySimulation: симуляция предыстории с исполнением плана

## Описание

Истина создаётся симуляцией мира, а не описанием (generation-pipeline.md §2, стадия 7).

## Цель

Журнал истины и знания персонажей на момент начала игры.

## Scope

- Запуск SimulationRunner с t = historyStart до 0.
- Цель ExecutePlot у виновника с высоким приоритетом.
- Если план сорван симуляцией (свидетель вошёл) — стратегия: перенос в пределах окна, иначе ошибка стадии → регенерация.
- IncidentRecord.keyEventIds из фактически исполненных событий.

## Out of Scope

- Следы (GEN-009).

## Зависимости

- [GEN-007](GEN-007.md) — Стадия PlotPlanning: план виновника, окно возможности, изгиб расписания
- [SIM-002](SIM-002.md) — Восприятие: наблюдения присутствующих → убеждения
- [SIM-003](SIM-003.md) — Встречи NPC и обмен знаниями, дрейф отношений
- [SIM-004](SIM-004.md) — Утилитарный планировщик целей и цели FollowRoutine, ExecutePlot

## Затрагиваемые модули

- `packages/generator/src/stages/history-sim.ts`

## Ожидаемый результат

Стадия симуляции предыстории.

## Критерии приёмки

- [ ] Truth проходит инварианты для 1000 seed.
- [ ] Инцидент исполнен в ≥ 95 % первых попыток на _test_minimal (иначе отчёт и тюнинг).
- [ ] Время стадии ≤ 200 мс (бюджет ADR 0013).
- [ ] `npm run tasks:check` и проверки CI зелёные.
