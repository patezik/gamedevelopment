# CNT-001 — Схемы контента сценариев (zod) и загрузчик @hs/core/content

## Описание

Пресеты — данные (docs/procedural-generation/scenario-presets.md). Нужны строгие схемы и загрузчик с перекрёстными проверками.

## Цель

Ошибки в данных сценариев ловятся при загрузке с понятным путём к полю.

## Scope

- zod-схемы: preset, locations, items, archetypes, relationships, motives, crimes, trace-rules, deduction-rules, text-шаблоны (каркас), phone-шаблоны (каркас).
- loadScenarioFromDir(dir) и ContentRepo.
- crossCheck: висячие ссылки на локации/архетипы/предметы, глаголы crimes без trace-rules.
- Скрипт npm run content:check (валидирует все content/scenarios/*).
- Минимальный тестовый сценарий content/scenarios/_test_minimal (используется в тестах).

## Out of Scope

- Полные данные MVP-сценария (CNT-002…).
- Семантика правил (реализуют модули-потребители).

## Зависимости

- [CORE-002](CORE-002.md) — Канонический JSON, хеширование состояния и генерация ID

## Затрагиваемые модули

- `packages/core/src/content`
- `content/`

## Ожидаемый результат

Загрузчик и схемы; content:check в CI.

## Критерии приёмки

- [ ] Каждая схема покрыта тестом «валидный пример» и «типичная ошибка».
- [ ] Ошибка содержит путь вида locations[3].connections[0].to.
- [ ] _test_minimal проходит content:check.
- [ ] content:check добавлен в CI.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Unit: схемы, crossCheck на сломанных фикстурах.

## Требования к документации

- docs/procedural-generation/scenario-presets.md — синхронизировать примеры со схемами.
