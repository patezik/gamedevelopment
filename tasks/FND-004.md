# FND-004 — Пакет @hs/protocol: конверт, ErrorCode, версия, экспорт JSON Schema

## Описание

Протокол — общий контракт сервера, мобильного приложения и Godot (ADR 0009). Нужен каркас пакета.

## Цель

Появляется единое место для схем сообщений с выводом TS-типов и экспортом JSON Schema.

## Scope

- packages/protocol с package.json (@hs/protocol), зависимость zod 4.6.x.
- PROTOCOL_VERSION = 1, ErrorCode (полный список из docs/backend/protocol.md §5), схема Envelope.
- Скрипт protocol:gen — экспорт JSON Schema в packages/protocol/schemas/; protocol:check — сравнение с закоммиченными.
- Каталог fixtures/ с примером envelope.

## Out of Scope

- Каталог конкретных сообщений (PROTO-001).
- Представления (PROTO-002).
- GDScript-константы (PROTO-003).

## Зависимости

- [FND-001](FND-001.md) — Корневой TypeScript-тулчейн: TS 6, ESLint 10, Prettier, Vitest 5

## Затрагиваемые модули

- `packages/protocol`

## Ожидаемый результат

Пакет собирается, экспортирует схемы и типы, JSON Schema генерируется детерминированно.

## Критерии приёмки

- [ ] import { Envelope, ErrorCode, PROTOCOL_VERSION } from "@hs/protocol" работает из другого workspace.
- [ ] npm run protocol:check проходит; изменение схемы без регенерации — падает.
- [ ] Пакет не имеет зависимостей, кроме zod.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Unit: валидные и невалидные конверты.
- Тест стабильности генерации JSON Schema (повторная генерация даёт тот же текст).

## Требования к документации

- docs/backend/protocol.md — ссылка на расположение схем.
