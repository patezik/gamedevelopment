# GEN-013 — Серверный результат генерации: улики, показания и правила дедукции

## Описание

Генератор проверяет улики, знания свидетелей и политики лжи, но успешный `GenerationResult` отдаёт только расследование, хеш и отчёт. Серверу нужно получить данные принятой попытки для настройки портов движка.

## Цель

Сервер может передать в движок улики, показания и правила обвинения из принятого дела без повторной генерации.

## Scope

- Описать типизированный серверный результат и вернуть улики, ID обязательных улик, знания и политики свидетелей, а также правила дедукции.
- Сохранить принадлежность всех данных к принятой попытке при перегенерации.
- Зафиксировать контракт в modules.md и generation-pipeline.md. Проверка на тестовых данных может использовать внедрённый набор проверок без изменения производственного шлюза.

## Out of Scope

- Клиентские представления, подключение портов в Session Server и изменение правил решаемости.
- Запись дополнительных данных в сохранения.

## Зависимости

- [GEN-011](GEN-011.md) — Генерация расследования и шлюз валидации.

## Затрагиваемые модули

- `packages/generator/src/generate.ts`
- `packages/generator/src/index.ts`

## Ожидаемый результат

Типизированный серверный контракт данных принятого расследования.

## Критерии приёмки

- [ ] Улики, знания, политики и правила совпадают с данными принятой попытки. Тест воспроизводит отклонение первой попытки.
- [ ] Публичный режим `hs-gen` и ошибки REST сохраняют существующий контракт без скрытых данных.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Интеграционные тесты генерации с повторной попыткой и регрессия публичного вывода CLI.
