# QA-003 — Инфраструктура локализации RU/EN (Godot и мобильное приложение)

## Описание

Тексты сейчас на русском; нужна возможность локализации.

## Цель

Добавление языка без правки кода.

## Scope

- Godot: TranslationServer + CSV/PO.
- Mobile: словари по ключам.
- Контент: text/<lang>/.
- Язык передаётся серверу при создании сессии.

## Out of Scope

- Перевод контента.

## Зависимости

- [GDT-004](GDT-004.md) — Сцена Exploration: локация, точки интереса, выходы, действия со стоимостью
- [MOB-001](MOB-001.md) — Оболочка виртуальной ОС: домашний экран, реестр приложений, статус-бар
- [CNT-005](CNT-005.md) — Текстовые шаблоны (RU): описания, показания, ложь, реакции, документы

## Затрагиваемые модули

- `apps/desktop`
- `apps/mobile`
- `content/`

## Ожидаемый результат

Инфраструктура i18n.

- [ ] Переключение языка в настройках; отсутствующий ключ — fallback на ru с предупреждением.
- [ ] `npm run tasks:check` и проверки CI зелёные.
