# SIM-001 — SimulationRunner: исполнение рутин NPC через Scheduler

## Описание

Персонажи действуют без игрока (character-simulation.md §3).

## Цель

NPC перемещаются по расписаниям, и каждое действие записывается в истину.

## Scope

- Agent, Activity, ActivityStep.
- Планирование шагов в фазе Schedules/Simulation; перемещение по пути с реальными длительностями.
- TruthEvent move/stay для каждого шага.
- Подпоток RNG sim/agent/<id>.

## Out of Scope

- Цели (SIM-004), наблюдения (SIM-002), LOD (SIM-007).

## Зависимости

- [CHAR-003](CHAR-003.md) — Расписания и рутины: whereShouldBe, переопределения
- [TIME-003](TIME-003.md) — TimeSystem.advance: фазы обработки, прерывания, события часов
- [TRUTH-002](TRUTH-002.md) — TruthLog, TruthModel и IncidentRecord

## Затрагиваемые модули

- `packages/core/src/simulation/runner.ts`

## Ожидаемый результат

Симуляция рутин.

## Критерии приёмки

- [ ] 24 ч без игрока: каждый NPC в каждой точке времени там, где говорит истина, и истина проходит инварианты.
- [ ] Одинаковый seed → одинаковый stateHash журнала.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Обязательный тест 10 из time-system.md §8; тест инвариантов.
