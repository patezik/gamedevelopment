# SRV-009 — Диагностика: структурированные логи, debug-истина по флагу

## Описание

Разбор багов по seed и журналу (truth-model.md §6).

## Цель

Разработчик может увидеть истину сессии в debug-режиме, а игрок — никогда.

## Scope

- GET /sessions/:id/debug/truth только при HS_DEBUG_TRUTH=1 и desktopToken.
- Логи с sessionId, без секретов.
- Команда экспорта сохранения как репро.

## Out of Scope

- Debug-панель Godot (GDT-011).

## Зависимости

- [SRV-001](SRV-001.md) — SessionManager: сессии, очередь действий, жизненный цикл

## Затрагиваемые модули

- `apps/server/src/diagnostics`

## Ожидаемый результат

Диагностика.

## Критерии приёмки

- [ ] Без флага эндпоинт 404.
- [ ] Тест: токены/коды не появляются в логах.
- [ ] `npm run tasks:check` и проверки CI зелёные.
