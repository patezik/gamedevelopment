# SRV-003 — Сервис привязки: коды, rate limit, токены устройств, POST /pair

## Описание

Безопасная привязка телефона (ADR 0008).

## Цель

Только телефон, отсканировавший код на экране игрока, получает доступ к сессии.

## Scope

- Код 6 символов Crockford Base32, TTL 5 мин, одноразовый.
- Rate limit 5/мин на IP, 20 неудач на сессию → аннулирование.
- POST /pair, POST /sessions/:id/pairing-code, DELETE /sessions/:id/device.
- deviceToken (хеш на сервере); повторная привязка отзывает старый (DEVICE_REVOKED).
- qrPayload hs1:pair:<host>:<port>:<code>.

## Out of Scope

- WS-аутентификация (SRV-004).

## Зависимости

- [SRV-001](SRV-001.md) — SessionManager: сессии, очередь действий, жизненный цикл

## Затрагиваемые модули

- `apps/server/src/pairing`

## Ожидаемый результат

Сервис привязки.
