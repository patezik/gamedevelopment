# INV-004 — Обнаружение противоречий между показаниями и фактами

## Описание

Противоречия — основной инструмент разоблачения лжи (investigation-model.md §4).

## Цель

Игрок видит противоречие, когда у него есть обе части.

## Scope

- detectContradictions(pk) по пропозициям (место/время с учётом размытия памяти).
- Событие ContradictionFound.
- Используется в допросе (предъявление).

## Out of Scope

- UI.

## Зависимости

- [INV-002](INV-002.md) — Утверждения (Claims) и правила дедукции

## Затрагиваемые модули

- `packages/core/src/investigation/contradictions.ts`

## Ожидаемый результат

Модуль противоречий.

## Критерии приёмки

- [ ] Нет ложных срабатываний на ошибки памяти в пределах fuzz.
- [ ] Противоречие не появляется при наличии только одной части.
- [ ] `npm run tasks:check` и проверки CI зелёные.
