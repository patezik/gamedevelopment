# GDT-004 — Сцена Exploration: локация, точки интереса, выходы, действия со стоимостью

## Описание

Основной экран исследования (godot-client.md §4).

## Цель

Игрок исследует локации, видит персонажей и стоимость каждого действия.

## Scope

- Отрисовка из PlayerView: фон локации (плейсхолдер по id), точки интереса, персонажи, выходы.
- Кнопка действия с costPreview («15 мин» / «20–30 мин»), подтверждение для долгих.
- Отображение ошибок action_failed.
- Карта перемещений (схема графа известных локаций).

## Out of Scope

- Финальный арт (CNT-010), эффекты (GDT-010).

## Зависимости

- [GDT-002](GDT-002.md) — Autoload GameStore и SceneRouter
- [ENG-002](ENG-002.md) — Проекция PlayerView и тест отсутствия утечек истины

## Затрагиваемые модули
