# INT-007 — Профиль Expo Development Build (EAS) как резерв к Expo Go

## Описание

Expo Go — только для разработки; релиз и нативные модули требуют собственной сборки (ADR 0007).

## Цель

Проект можно собрать без Expo Go в любой момент.

## Scope

- eas.json: профили development, preview, production.
- expo-dev-client в профиле development.
- Инструкция по сборке и установке.

## Out of Scope

- Публикация в магазинах (REL-002).

## Зависимости

- [FND-006](FND-006.md) — Bootstrap apps/mobile: Expo SDK 58, Expo Router, TypeScript, jest-expo

## Затрагиваемые модули

- `apps/mobile/eas.json`
- `docs/mobile/mobile-app.md`

## Ожидаемый результат

Профили сборки.

## Критерии приёмки

- [ ] Development-сборка запускается на Android-устройстве (лог/скриншот).
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- Ручной.
