# FND-002 — ESLint-правила детерминизма и границ импорта

## Описание

ADR 0004 запрещает недетерминированные API в ядре, генераторе и валидаторе; ADR 0001/0002 запрещают мобильному приложению импортировать ядро, а модулям расследования — Truth Model.

## Цель

Нарушения детерминизма и границ модулей ловятся линтером, а не ревью.

## Scope

- no-restricted-properties/no-restricted-globals для Math.random, Date.now, performance.now, new Date() в packages/core, packages/generator, packages/validator.
- no-restricted-imports: apps/mobile не импортирует @hs/core, @hs/generator, @hs/validator.
- no-restricted-imports: packages/core/src/investigation/** (кроме accusation.ts) не импортирует ../truth.
- Документировать правила в docs/development/coding-standards.md.

## Out of Scope

- Произвольные стилистические правила.

## Зависимости

- [FND-001](FND-001.md) — Корневой TypeScript-тулчейн: TS 6, ESLint 10, Prettier, Vitest 5
- [FND-009](FND-009.md) — Каркасы пакетов @hs/core, @hs/generator, @hs/validator

## Затрагиваемые модули

- `eslint.config.mjs`

## Ожидаемый результат

Попытка использовать запрещённое API или импорт приводит к ошибке lint с пояснением.

## Критерии приёмки

- [ ] Каждое правило имеет сообщение со ссылкой на ADR.
- [ ] Тестовый фикстурный файл с нарушениями (в каталоге, исключённом из сборки) даёт ожидаемые ошибки — проверяется скриптом в тесте.
- [ ] npm run lint зелёный на основном коде.
- [ ] `npm run tasks:check` и проверки CI зелёные.

## Требования к тестированию

- tools/lint-fixtures/: файлы с нарушениями + тест, запускающий ESLint API и сравнивающий список ошибок.

## Требования к документации
