# GDT-012 — Иллюстрации локаций и портреты на экранах desktop

## Описание

Exploration показывает плейсхолдер-фон (оттенок из `location.id`), хотя пайплайн и эталонные
пластины уже есть ([art-direction.md](../docs/game-design/art-direction.md), CNT-010). Нужно
показывать пластину локации и портреты присутствующих персонажей по правилам стайлгайда.

## Цель

Экран Exploration рисует пластину по `location.id` и текущему `location.lighting`, а
персонажей — с портретами по `portraitRef`; при отсутствии арта остаётся заглушка.

## Scope

- Общий компонент `src/ui/art_library.gd`: путь пластины `scenarios/<scenario>/locations/<id>.<lighting>.png`
  и портрета `scenarios/<scenario>/portraits/<portraitRef>.png`; загрузка по требованию
  (`ResourceLoader.load_threaded_request`), кэш текущей и соседних локаций; отсутствующий файл —
  `null` без ошибки.
- Exploration: пластина ×3, `texture_filter = TEXTURE_FILTER_NEAREST`, целый масштаб; смена
  уровня освещения — переход затемнением; плейсхолдер, если пластины нет.
- Портреты персонажей ×2 в рамке `ui/frames/photo_frame.png` (9-slice); пустой `portraitRef`
  или отсутствующий файл — силуэт-заглушка.
- Предложение по `display/window/stretch/scale_mode = "integer"`: проверить влияние на весь
  интерфейс и принять или отклонить с обоснованием в godot-client.md.

## Out of Scope

- Заполнение `portraitRef` сервером (ENG-008).
- Новые ассеты (CNT-012).
- Доска дела и диалог (используют `art_library.gd` в своих задачах).

## Ожидаемый результат

Экран Exploration с иллюстрациями и портретами.

## Критерии приёмки

- [ ] Для локаций с артом показывается пластина нужного уровня освещения ×3 без размытия.
- [ ] Для локаций без арта и при пустом `portraitRef` экран работает с заглушками без ошибок.
- [ ] Клиент не выводит из арта ничего, чего нет в `PlayerView`.
- [ ] `npm run test:godot` и проверки CI зелёные.

## Требования к тестированию

- GUT: выбор пути по `location.id`/`lighting`, заглушка при отсутствии файла, nearest-фильтрация
  и целый масштаб узла пластины.
